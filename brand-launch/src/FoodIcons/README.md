# 음식 종류 아이콘

- Studio: `Food-Icons / FoodIcons-Grid` — 현재 앱의 음식 종류 32개, 기본 8열 × 4행, 1920 × 1280.
- `Food-Icons / FoodIcons-Transition` — 1080 × 1080 정사각형, 그리드의 모션 아이콘 13개가 각자 한 주기 움직인 뒤 선으로 이어지는 약 72.62초 루프.
- `Food-Icons / Individual / FoodIcon-*` — 아이콘별 1080 × 1080 화면.
- 화면에는 이름 없이 아이콘만 표시한다. 그리드와 전환 영상은 흰색 배경과 그라데이션 선을 사용한다. 크기·재생·모션 속도·강도와 그리드 열 개수는 Studio Props에서 조절한다. 개별 아이콘 영상은 기존 배경·아이콘 색 설정을 유지한다.
- 웍(`FoodIcon-stir-fried-wok`), 조림(`FoodIcon-braised`), 면류(`FoodIcon-noodle`), 구이(`FoodIcon-grilled`), 해조류(`FoodIcon-seaweed`), 훈연(`FoodIcon-smoked`), 국물(`FoodIcon-broth`), 전·부침(`FoodIcon-pancake`), 음료/페어링의 와인잔(`FoodIcon-beverage-pairing`), 과일(`FoodIcon-fruit`), 찜·스팀(`FoodIcon-steamed`), 디저트(`FoodIcon-dessert`), 향신료(`FoodIcon-spice`)가 그리드에서 움직이며, 나머지 19개는 원본 정지 상태다. 두부/콩의 완두콩은 그리드에서 원본 기본 아이콘으로 표시하고, 개별 미리보기(`FoodIcon-legume-tofu`)에서만 모션을 재생한다.
- 전체 그리드는 기본 60fps · 600프레임의 10초 미리보기이며, 속도 변경에 맞춰 영상 길이도 조절한다. 각 아이콘은 그리드 길이와 별개로 자기 주기를 계속 반복한다. 공통 시간 설정은 `timing.ts`에서 관리한다.
- 그리드 배경은 완전한 흰색이다. 결과 카드의 `DiningFeedbackMotion/Background.tsx`를 하나의 전체 화면 색상 레이어로 재사용하고, 기존 32개 아이콘의 움직이는 SVG 선을 마스크로 드러낸다. 아이콘마다 별도 그라데이션을 만들지 않으며 선 안의 위치에 따라 같은 색상 흐름이 이어진다. 결과 카드의 번짐·sin/cos 이동을 사용하되, 그리드에서는 색 영역의 이동 범위를 2배로 넓히고 시간 진행은 결과 카드 기준 1.2배로 적용한다(이전 1.6배보다 25% 느리게). 결과 카드 자체는 기존 기본값을 유지한다. 색은 넓은 메인 1색(주색 영역 비중 0.60)과 보조 1색, 총 2색으로 구성한다. 단맛+신맛 → 신맛+쓴맛 → 쓴맛+짠맛 → 짠맛+감칠맛 → 감칠맛+지방맛 → 지방맛+단맛 순서로 계속 순환한다. 기존 두 보조 영역은 같은 보조색을 공유하고 움직임은 유지한다. 카드 전환의 감속 곡선 대신 연결 지점에서도 속도가 이어지는 닫힌 3차 색상 보간을 사용해 각 색에서 멈추지 않는다. 전체 색상 순환은 10초 그리드 주기에 맞춘다. 그라데이션 레이어의 채도와 밝기는 모두 원본 100%를 유지한다. `재생: 정지`는 아이콘과 그라데이션을 함께 멈춘다. 시작·마지막 프레임의 색상과 움직임이 같아 반복이 이어진다. 기존 틴트 배경 전환과 관련 설정은 제거했다. 원본 SVG의 선 두께·마스크·클립·점·불투명도, 열별 배치와 개별 모션을 유지한다.
- 웍은 짧게 당겼다 되돌리기 두 번 → 크게 튕기고 받아내기 → 제자리 → 크게 튕기고 받아내기 → 제자리 순서로 움직인다. 준비 동작은 처음에만 두 번이며 팬만 움직인다. 이어지는 두 번의 큰 튕김에서는 점과 선이 함께 나온다.
- 조림은 증기 그래픽 없이 냄비를 고정하고 뚜껑·손잡이만 움직인다. 닫힌 뚜껑이 서로 다른 높이와 기울기로 세 번 들썩인다. 세 번째 최고점은 기본 강도에서 원본 조림 아이콘의 열린 뚜껑 위치·기울기와 일치하며, 강도를 높여도 원본 높이를 넘지 않는다. 마지막 착지 후 작게 한 번 반동한 뒤 닫힌다.
- `재생`을 `정지`로 바꾸면 각 아이콘의 시작 자세를 유지한다. `모션 속도`(0.5–2배), `모션 강도`(0.5–1.5배)를 조절할 수 있다.
- 해조류는 밑동을 고정하고 위쪽으로 갈수록 크게 좌우로 흔들린다. 짧은 줄기는 긴 줄기보다 조금 늦게 따라온다. 새우튀김 외곽처럼 물결이 고르게 이어지도록 휘어진 양쪽 윤곽 각각의 길이를 기준으로 원본 물결 간격과 깊이를 유지한다. 원본 네 경로를 사용하며 선 두께 2를 유지한다.
- 훈연은 중앙 → 왼쪽 → 오른쪽의 시차를 두고 원본 연기 곡선을 아래에서 위로 흐른다. 각 경로에서 앞선 선이 사라지기 전에 다음 선이 올라오며, 위쪽 소멸 구간에만 점이 잠깐 나타난다. 한 경로에는 점이 최대 한 개이며, 아래 장작은 고정한다.

채소/허브는 Lucide `leafy-green`, 견과·씨앗은 Lucide `nut`의 공식 1.50.0 SVG를 사용한다. 두 아이콘 모두 원본 24 × 24 좌표와 2px 획을 유지하며 별도 모션은 없다.

종류와 개별 선택 목록의 순서는 앱의 `src/constants/dishKindTags.ts`에 있는 `DISH_KIND_OPTIONS`를, SVG 형태는 `src/constants/dishKindIcons.ts`를 직접 사용한다. 과거 기록 호환용 통합 종류는 현재 목록에 포함하지 않는다. 원본 24 × 24 좌표와 선 두께 2를 유지한다.

그리드에서는 `grid-layout.ts`의 열 수별 전용 순서를 사용한다. 그릇·냄비·병·둥근 외곽·대각선 형태가 가까이 반복되지 않도록 섞고, 움직이는 13개 아이콘은 상하좌우로 붙지 않게 분산한다. 기본 8열에서는 각 행에 모션을 4·3·3·3개 배치한다. 4–8열 각각에 고정 배치를 두어 재생·탐색 중 순서가 바뀌지 않는다. 원본 카탈로그와 개별 아이콘 목록 순서는 유지하며, 나중에 추가된 종류도 누락하지 않고 그리드 뒤에 표시한다.

`FoodIcon.tsx`에서 SVG 조각을 각각 렌더링하며 `data-icon-part`로 식별할 수 있다. 개별 아이콘 모션을 추가할 때 이 컴포넌트를 진입점으로 사용한다.

## 정사각형 아이콘 모핑

`FoodIcons-Transition`은 1080 × 1080 · 60fps이며, 그리드에서 움직이는 13개를 전환 영상 전용 순서로 표시한다. 웍 → 전 → 조림 → 찜 → 향신료 → 디저트 → 과일 → 와인 → 국물 → 면류 → 해조류 → 훈연 → 구이 순서다. 그리드에서 정지한 완두콩은 포함하지 않는다. 각 아이콘의 기존 2.5초·5초·10초 모션을 재생한 뒤 0.35초 동안 다음 아이콘으로 모핑한다. 사과는 마지막 입과 반응이 끝나는 약 3.05초의 심 모습에서 바로 와인으로 연결하며, 심이 사라지고 온전한 사과가 위에서 떨어지는 복귀 구간은 생략한다. 다른 아이콘은 한 주기를 완주한다. 기본값은 약 72.62초(4357프레임)이며 마지막 구이에서 첫 웍으로도 연결된다.

기본 크기는 320px이다. 배경은 흰색으로 고정하고, 그리드와 같은 미각 2색 그라데이션을 움직이는 아이콘 선과 모핑 중인 선에 마스킹한다. 채도와 밝기는 100%이며, 미각 순서·이동 범위·색 흐름을 그리드와 공유한다. 색상 흐름은 그리드의 약 10초 주기와 비슷한 속도로 반복하되 전체 영상의 처음과 끝이 일치하도록 정수 회전으로 맞춘다(기본 72.62초 동안 7회). 크기·모션 속도·모션 강도·모션 후 정지 시간·전환 시간·재생/정지는 Studio Props에서 조절한다. 기본 추가 정지는 0초이며, 속도를 바꾸면 각 아이콘의 기존 주기와 전체 영상 길이가 함께 바뀐다. 이름이나 보조 문구는 표시하지 않는다.

모션 구간은 기존 `FoodIcon`을 로컬 프레임으로 재생한다. 전환은 실제 모션의 마지막 SVG 모습에서 다음 모션의 첫 모습으로 좌표를 보간한다. 빈 와인잔, 다 먹은 사과 심, 닫힌 뚜껑, 변형된 해조류와 부분 증기를 포함하며 중간에 카탈로그 정지 모양을 끼워 넣지 않는다. 큰 윤곽부터 위치·길이·닫힘 여부에 따라 연결하고, 닫힌 선의 방향과 시작점을 맞춘다. 수가 다른 세부 선은 가까운 선에서 자라거나 합쳐진다. 전체 아이콘의 위치·크기·선 두께와 round cap/join을 유지한다. 기존 그리드·개별 모션은 변경하지 않는다.

`Transition.tsx`가 렌더링, `transition-motion.ts`가 순서와 주기, `capture-transition-pose.ts`가 실제 SVG의 변환·마스크·클립·점선이 적용된 경계 모습 추출, `transition-shapes.ts`가 경로 대응과 보간, `transition-settings.ts`가 속성을 담당한다. 경계 모습은 속도·강도·fps가 달라질 때 갱신한다. 원본 SVG 파일과 각 모션 구현은 그대로 사용한다.

## 그리드 길이와 개별 반복 주기

기본 속도 1에서 전체 그리드는 10초다. 국물은 한 번 완주하고, 짧은 모션은 각자의 주기로 여러 번 반복한다. 개별 주기는 2.5초·5초·10초로 맞춰 그리드의 마지막 프레임에서 모든 아이콘이 처음 모습으로 돌아온다. 중간 동작을 정지시키지 않으며, 향신료·조림·전의 추가 여유는 완성된 시작 자세에서만 둔다. 원래 속도로 복구한 여덟 아이콘은 주기가 끝나면 바로 다음 반복을 시작한다.

| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 면류·해조류           | 원래 2.5초 주기와 동작 속도로 복구. 그리드에서 네 번 반복한다.                                                                                                                                       |
| 디저트·과일·와인·구이 | 원래 5초 주기와 동작 속도로 복구. 그리드에서 두 번 반복한다.                                                                                                                                         |

| 찜·스팀               | 원래 5초 주기로 복구. 물결은 한 주기에 세 차례 반복하고, 손잡이는 기존 속도로 열두 번씩 흔들리는 구간을 두 번 수행한다.                                                                              |

시간 설정은 `timing.ts`에서 분리한다. `foodIconOriginalTiming`은 복구한 5초 계열과 반복 주기를 줄인 웍, `foodIconTiming`은 10초 계열(조림·전은 절반인 5초), `brothTiming`은 국물 10초, `foodIconGridTiming`은 그리드 10초에 사용한다. 개별 미리보기는 `foodIconSingleTiming`으로 선택한 아이콘의 실제 주기 길이를 따른다. 프레임 수는 기본 속도에서 150·300·600이며 그리드는 600프레임이다. `모션 속도`는 각 주기와 그리드 길이에 동일하게 적용한다. 국물의 별도 스팀 배속은 1.7을 유지한다.

## 상세 동작과 기준 키프레임

아래의 초·프레임 수치는 모션 계산에 사용하는 기준 키프레임이다. 복구한 여덟 아이콘은 원래 시간값 그대로 재생한다. 웍·조림·전·향신료의 실제 재생 시각은 위 표를 따른다. 국물은 스팀 이후 젓는 구간에만 시간을 추가한다.

향신료는 절구와 받침을 고정하고 공이만 움직인다. 5초마다 세워진 공이를 두 번 들어 찧고(0.30–0.74초, 0.82–1.26초), 절구 안쪽을 누르며 두 바퀴 갈아낸 뒤 부드럽게 복귀한다. 올릴 때보다 내려치는 시간을 짧게 둔다. 갈 때는 국물 숟가락을 참고한 좌우 반경 2.7, 상하 반경 0.58의 납작한 타원을 따라 공이의 회전축이 이동하며, 세운 자세에서 좌우 최대 23도씩 함께 기울어진다. 1.36–1.60초에 오른쪽 끝으로 진입한 뒤 1.60–4.20초의 2.6초 동안 아래쪽 중앙 → 왼쪽 → 위쪽 중앙 → 오른쪽 궤도를 두 바퀴 연속으로 돈다. 중간에 멈추거나 중앙으로 복귀하지 않는다. 4.20–4.80초의 0.60초 동안 중앙으로 부드럽게 돌아온다. 복귀 시작과 끝의 속도를 0으로 낮춰 갈기에서 대기 자세까지 자연스럽게 잇는다. 타원을 도는 동안 이동 반경은 일정하며 짧은 가속·감속 구간 사이에서는 일정한 속도로 움직인다. 4.80초에 빻기 직전의 세운 자세로 돌아온 뒤 다음 찧기까지 그대로 유지한다. 원본의 오른쪽 기울기로 복귀하는 추가 회전은 넣지 않는다. 원본 공이 윤곽은 유지하고 절구 안에 가려진 끝만 연결해, 들어 올리거나 회전할 때 열린 선 끝이 나타나지 않도록 한다. 절구 앞쪽 테두리가 잠긴 부분을 가린다. 선 두께는 2이며 시작·끝·정지 상태는 모두 빻기 직전의 세운 자세다. 동작은 `spice-motion.ts`, SVG 연결은 `Spice.tsx`에서 관리한다.

전·부침은 면·조림과 같은 2.5초 주기(5초 미리보기에서 두 번)로 반복하며 0.20초부터 공중으로 솟아 중심의 가로축을 기준으로 두 바퀴(720°) 뒤집힌다. 기본 60fps·속도 1에서 48프레임부터 마지막 회전의 높이를 낮추고, 64프레임(약 1.067초)에 약 646.8°로 기울어진 자세로 아래끝이 바닥에 처음 닿는다. 회전하는 원형 테두리의 최하단을 기준으로 하강을 계산해 접촉 전에는 바닥을 통과하지 않는다. 접촉 뒤에는 이미 붙은 부분을 원본 위치에 고정하며, 접촉 경계가 원본 y=21에서 y=3으로 올라가는 동안 아직 들린 면이 남은 회전을 마친다. 첫 접촉부터 완전히 펼쳐질 때까지 0.45초(27프레임)를 쓰며, 91프레임(약 1.517초)에 두 바퀴 회전과 전체 착지가 끝난다. 완전히 펼친 자세로 약 0.98초를 유지한 뒤 다음 주기가 시작된다. 공중 회전 속도와 접촉 후 펼침 시간은 유지하고 시작 대기와 반복 간격을 면·조림의 리듬에 맞췄다. 원본 원형 테두리와 내부 무늬는 같은 3D 회전·원근 투영을 적용한다. 앞면에는 원본 무늬를 표시하고 뒷면에서는 감춘다. 옆면과 두께 표현 없이 원본 원형 테두리 하나만 회전한다. 착지할 때 좌우 폭을 고정하고 세로 방향은 안쪽으로만 짧아지도록 제한하며, 붙은 부분과 들린 부분의 곡선을 부드럽게 잇는다. 테두리·무늬의 선 두께는 2다. 회전하는 아이콘 전체의 기본 최고 상승 높이는 원본 좌표 기준 9이며, `모션 강도`는 떠오르는 높이를 조절한다. 시작·끝·정지 상태는 원본 형태와 같다. 동작은 `pancake-motion.ts`, SVG 연결은 `Pancake.tsx`에서 관리한다.

훈연은 원본 SVG의 세 곡선을 역순으로 탐색해 아래에서 위로 이동한다. 중앙은 0.10초, 왼쪽은 0.40초, 오른쪽은 0.70초를 기준으로 새 선이 들어오며, 각 경로에서 기본 2.5초 간격(5초당 두 번)으로 이어지며, 원본 경로를 따라 올라오는 속도를 기존의 약 3분의 2로 낮춘다. 각 선의 길이는 원본 연기 곡선 전체 길이와 같으며, 경로 안으로 들어오고 나갈 때만 끝부분이 잘린다. 선과 점의 여백을 더한 간격으로 다음 선이 들어와 앞선 선의 꼬리와 잠깐 겹쳐 보인다. 두 선 사이의 점은 뒤따르는 선 쪽에 두며, 기본 강도에서 앞선 선과 점 사이 여백은 원본 좌표 기준 약 3.02, 점과 다음 선 사이는 0.72로 둔다. 앞선 선과 점 사이 여백을 이전 7:3 배치보다 80% 넓힌 값이다. 점은 원본 경로의 위쪽 24%에 들어온 뒤에만 나타나고, 끝으로 갈수록 작아지며 사라진다. 아래쪽과 중간에는 점을 표시하지 않는다. 선과 점 모두 같은 원본 경로상의 길이 좌표를 사용한다. `모션 강도`는 선과 점 사이 간격을 조절한다. 시작부터 이어진 연기 상태이며 5초 주기의 시작·끝 배치가 같아 빈 구간 없이 반복된다. 동작은 `smoked-motion.ts`, SVG 연결은 `Smoked.tsx`에서 관리한다.

국물은 그릇과 받침을 고정하고 물결을 두 차례 내보낸 뒤, 물결이 완전히 사라진 다음에만 숟가락을 움직인다. 순서는 물결 소멸 → 숟가락을 세우면서 크게 젓기 → 뜨는 각도로 돌리기 → 들어 올리기 → 반시계 방향으로 살짝 기울이기 → 원위치 복귀다. 수직으로 세워지는 순간부터 손잡이가 타원 경로를 따라 회전하며, 앞쪽 헤드는 국물 안에 잠긴 상태로 가린다. 완전히 수직이 되기 전에도 회전이 진행되고, 수직이 된 뒤 멈춤 없이 이어서 총 두 바퀴를 연속으로 완성한다. 수직 상태의 타원은 좌우 반경 3.1, 상하 반경 0.65다. 오른쪽 끝에서 왼쪽으로 갈 때 중앙에서 0.65만큼 내려갔다가 왼쪽 끝에서 기준 높이로 돌아오고, 다시 오른쪽으로 갈 때 중앙에서 같은 만큼 올라갔다가 오른쪽 끝으로 돌아온다. 모션 강도로 타원 크기를 조절하며, 수직 자세가 완성된 뒤에는 타원 크기가 일정하다. 중앙에 세운 뒤 옆으로 이동하거나 회전을 시작하는 별도 구간 없이, 기존 자세에서 세우기와 타원 회전을 동시에 부드럽게 보간한다. 회전을 마친 오른쪽 끝에서 곧바로 뜨는 자세로 연결해 종료 때도 중앙으로 급히 복귀하지 않는다.

국물은 두 번째 물결이 실제로 끝난 뒤 숟가락을 움직인다. 스팀은 기준 시간의 1.7배 속도로 두 차례 방출하며, 소멸 시각은 현재 원본 경로의 길이와 모션 강도로 계산한다. 기존 8초 동작의 스팀·세우기·들기·기울이기·복귀 시간은 유지하고, 젓는 구간에만 실제 재생 시간 2초를 더한다. 한 번의 연속 타원 운동 안에서 총 720도, 두 바퀴를 돌며 첫 바퀴 끝에서 멈추지 않는다. 젓기가 끝나면 뜨는 각도로 돌려 들어 올리고, 앞쪽 헤드 중심을 축으로 뒤쪽 손잡이가 반시계 방향으로 8도 올라갔다가 돌아온다. 이어 내리고 원래 각도로 복귀해 10초 주기를 마친다. 회전의 맨 처음과 맨 끝에만 코사인 가감속을 적용한다.

국물 숟가락의 손잡이 길이는 약 9.16이며, 들어 올렸을 때 앞쪽 헤드 중심을 그릇 중심 x=12로 맞춘다. 헤드는 폭 5, 깊이 1.1의 닫힌 반타원이고, 손잡이와의 35도 꺾임을 유지한다. 손잡이 뒤끝 (22, 6)을 기준으로 뜨는 자세를 만든 뒤, 숟가락 전체를 약 4.35만큼 들어 올려 수평 헤드 자세에서 헤드 아래와 그릇 테두리 사이의 실제 여백을 2px로 맞춘다. 반시계 방향으로 살짝 기울이는 동안에도 헤드는 그릇 테두리 위에 머문다. 그릇의 실제 윤곽으로 물에 잠긴 부분을 가린다. 원본 그릇과 받침, 선 두께 2는 유지한다.

국물의 물결은 시작할 때 보이던 중앙·왼쪽·오른쪽 세 선이 각자 원본 경로 끝까지 올라간 뒤 두 번째 묶음이 같은 경로를 따라 올라가 사라진다. 공통 물결의 첫 번째·두 번째 궤적을 사용하며 세 번째 묶음은 표시하지 않는다. 훈연의 `smokedLane`을 공유하며 원본 물결 곡선을 유지하고, 국물에서만 시간값을 1.7배 빠르게 진행한다. 찜·스팀 아이콘의 속도는 바꾸지 않는다. 선의 앞과 뒤가 계속 전진하며, 중간에 전체 불투명도를 낮추지 않고 끝에서 자연스럽게 소멸한다. 점은 표시하지 않는다. 숟가락 동작이 끝난 뒤 다음 반복 직전에 물결이 다시 나타난다. 이때는 다음 주기 시작 직전의 물결 시간값을 사용해 빨라진 스팀도 반복 경계에서 끊기지 않도록 연결한다. 시작·끝·정지 상태는 같은 숟가락 자세와 물결 배치다. 숟가락 자세는 `broth-spoon-motion.ts`, SVG 연결은 `Broth.tsx`, 공통 물결은 `SteamField.tsx`에서 관리한다.

해조류는 `y=19`의 밑동과 아래 두 줄기 선을 고정한다. S자 적용 전의 움직임대로 높이에 따라 좌우 이동량을 키우고, 위쪽과 짧은 줄기에 반응 지연을 둔다. 원본 중심선의 움직임을 유지하면서 안쪽과 바깥쪽 윤곽을 각각 호 길이로 재배치해 물결 간격과 깊이를 유지한다. 휘어지며 생기는 작은 길이 차이는 물결이 없는 둥근 끝부분에서만 흡수한다. 시작·끝·정지 상태는 원본 경로이며, 동작은 `seaweed-motion.ts`, SVG 연결은 `Seaweed.tsx`에서 관리한다.

웍은 5초 주기에서 준비 동작 두 번 뒤에 큰 튕김을 두 번 이어서 수행한다. 큰 튕김은 원래 동작보다 1.25배 빠르게 재생한다. 첫 큰 동작은 0.70초에 시작해 약 1.79초에 제자리로 돌아오고, 두 번째는 1.86초부터 같은 속도와 궤적으로 반복해 약 2.95초에 복귀한다. 두 큰 동작 사이에는 준비 동작을 넣지 않는다. 시작과 끝에는 팬·손잡이만 보인다. 당겼다가 튕길 때 점이 먼저 나오고 짧은 선이 뒤따르며, 원본 상단 원호(`M5 9 A6 6 0 0 1 10 6`)의 중심을 기준으로 함께 회전한다. 점의 중심과 선의 중심선 모두 같은 반지름 6의 원호 경로를 따른다. 원본 SVG의 점과 선을 같은 그룹에서 변환하므로 24 × 24 좌표 기준 외곽 간격 1px를 이동 내내 유지한다. 둘 다 왼쪽 팬 안에서 나와 위로 솟은 뒤 오른쪽 팬 안으로 돌아간다. 팬과 함께 기울어지는 가장자리 가림 영역이 출발·복귀를 처리하며, 페이드로 등장하거나 공중에서 사라지지 않는다. 원본 SVG 선 모양과 색상은 유지한다. 동작은 `wok-motion.ts`, SVG 연결은 `Wok.tsx`에서 관리한다.

조림은 원본 뚜껑 선(`M4 8 L20 4`)과 손잡이를 같은 그룹으로 묶는다. 원본 기울기를 수평으로 되돌리고 냄비 입구에 내려놓은 상태가 시작·종료 자세다. 수직으로 들렸다가 중력처럼 가속하며 내려오는 동작에 좌우 기울기를 더해 증기 압력에 들썩이는 무게감을 표현한다. 동작은 `braised-motion.ts`, SVG 연결은 `Braised.tsx`에서 관리한다.

면류는 그릇과 빈 젓가락으로 시작한다. 젓가락 뒤끝에서 중심 방향으로 1.5만큼 옮긴 축 `(19.5, 5.786)`을 기준으로 앞쪽을 기울여 그릇에 담그되, 뒤쪽에도 작은 이동을 더한다. 가림 영역은 그릇 폭 `x=3–21`로 한정해 바깥으로 나온 뒤쪽을 자르지 않는다. 그릇 안에서 잠시 멈춘 뒤 위로 건져 올리면 원본 면 3줄이 수직으로 드러난다. 건져 올릴 때는 각 면의 위쪽 연결점이 젓가락의 회전·이동을 따라가며 아래쪽은 그릇 가장자리에 머문다. 건진 뒤에는 젓가락과 면이 함께 짧게 두 번 위아래로 움직인다(1.34–1.60초, 1.64–1.94초). 웍처럼 박자 사이를 짧게 끊고, 조림의 앞 두 들썩임처럼 두 번째를 조금 더 길고 크게 잡는다. 이 구간에는 면의 길이를 유지하며, 두 동작이 끝난 2.00–2.42초에 아래 끝부터 위로 짧아져 사라진다. 그릇 앞쪽 가장자리가 담긴 젓가락 끝과 면을 가리고, 마지막 빈 젓가락 자세는 처음과 같아 반복이 이어진다. 동작은 `noodle-motion.ts`, SVG 연결은 `Noodle.tsx`에서 관리한다.

구이는 장작을 고정하고 불꽃과 소멸 후의 짧은 연기를 표현한다. 공통 5초 미리보기 안에서 한 주기를 완성하며, 불꽃 밑동 `(12, 15)`으로부터 0.2초 동안 점화되어 원래 크기로 자란다(0.12–0.32초). 0.32–2.86초에는 켜진 상태로 천천히 흔들린다. 2.86–3.34초에는 윤곽을 온전히 유지한 채 바람에 곡선이 휘고 오른쪽으로 조금 밀리는 모습을 먼저 보여준다. 원본 원호와 베지어 구간을 유지한 채 아래쪽 안쪽 굴곡은 1.6초 주기로, 불끝은 약 0.8초를 기준으로 더 빠르게 왕복한다. 불끝에는 서로 다른 주기의 연속 파형을 섞어 좌우로 뻗는 폭과 방향 전환 시점이 매번 조금씩 달라지도록 했다. 프레임마다 튀지 않고 부드럽게 이어지며, 같은 프레임을 다시 재생하면 같은 모습이 나온다. 밑동은 안정적으로 유지한다. 흔들림은 점화 직후 부드럽게 시작하고, 마지막 바람이 들어오면 점차 잦아든다. 불끝과 인접 제어점은 함께 이동하고, 안쪽 원호는 반지름을 유지한 채 약간의 시간차를 두고 반대 방향으로 조금 이동한다. 평상시에도 오른쪽 어깨와 바깥 곡선이 불끝보다 약간 늦게 오른쪽으로 밀렸다가 돌아온다. 밑동을 고정한 채 위로 갈수록 더 많이 움직이는 연속 변위를 사용해 곡선의 매끈한 연결을 유지한다. 바람 구간에는 밑동의 이동을 작게 두고, 위로 갈수록 더 많이 밀리도록 높이에 비례한 수평 변위를 공통 경로에 적용한다. 제어점도 함께 이동해 곡선의 매끈한 연결을 유지하며 선 두께는 변형하지 않는다. 점화 때만 크기를 키우며, 타는 동안과 선이 끊어지는 소멸 구간에는 원본 크기를 유지한다. 바람의 이동은 2.86–3.72초 동안 하나의 연속 곡선으로 이어지며, 소멸 시작점에서 멈추거나 다시 가속하지 않는다. 불꽃을 휘게 하는 바람도 3.42초까지 이어져 첫 틈이 생기는 구간과 겹친다. 3.34–3.72초에는 계속 밀리는 도중 윤곽선 중간의 틈이 넓어지며 위에서 아래로 사라진다. 소멸 시간은 0.38초이며, 다섯 곡선의 윗부분부터 짧아지고 마지막 밑동으로 모여 사라지도록 높이에 따라 시작·종료 시점을 달리한다. 열린 틈 사이에는 짧은 선 두 개와 둥근 점 두 개가 잠시 남고, 이 잔선과 점도 윗부분부터 사라진다. 잔선 위치는 실제 틈의 가운데를 따라가며 이웃 선의 둥근 끝과 겹치지 않도록 제한한다. 긴 곡선·짧은 선·점은 모두 동일한 불꽃 경로와 공통 이동값을 공유하므로, 웍의 원호와 점처럼 같은 경로 위에 정렬된다. 큰 곡선과 작은 잔선·점이 함께 오른쪽으로 밀리면서 짧아지고 가늘어져 사라진다. 이 소멸 구간에서는 불꽃 전체를 회전하거나 축소하지 않는다. 불이 완전히 꺼진 뒤 3.78–4.46초에는 훈연 아이콘의 가운데 원본 경로를 따라 짧은 연기 선 하나가 아래에서 위로 한 번 올라간다. 이동 경로는 원본의 아래쪽 62%, 선 길이는 원본 경로의 24%로 줄였다. 짧아진 경로의 윗부분에서는 선 앞에 작은 점 하나가 나타나 같은 곡선을 따라 올라가며 가늘어져 사라진다. 연기는 0.68초 안에 빠르게 소실되며, 양옆 연기는 추가하지 않는다. 시작과 끝에는 장작만 남는다. 구이는 5초 미리보기에서 한 번 반복하며, 다른 아이콘과 미리보기의 시작·종료 경계를 공유한다. 타는 동안 기본 선 두께 2를 유지한다. `모션 강도`는 불꽃 곡선이 휘는 폭을 조절한다. 동작은 `grilled-motion.ts`, SVG 연결은 `Grilled.tsx`에서 관리한다.

와인잔은 5초 주기에 한 번 빈 잔 → 위에서 따르기와 채워짐 → 중앙 점의 상승·낙하 → 에어링 물결 → 들어 올려 반시계방향으로 기울이며 비우기 → 빈 잔 복귀를 연결한다. 0.32–1.76초에 왼쪽 위에서 부드럽게 휘어 들어오는 곡선을 앞끝부터 드러내고 위쪽 끝부터 끊어 흘려보낸다. 줄기는 1.44초부터 0.32초 동안 짧아지며, 수면이 목표 높이에 도달하는 1.76초에 정확히 사라진다. 채워짐과 줄기 소멸은 같은 완료 시점을 공유하며, 따르는 동안의 잔물결도 이때 잦아든다. 줄기가 사라진 뒤 1.80–2.28초에는 수면 중앙 x=12에서 속이 찬 작은 원형 점 하나가 튀어 오른 뒤 포물선을 따라 다시 수면으로 떨어진다. 점의 지름은 와인 선 두께와 같은 2로 고정하고, 출발·복귀 때 크기 대신 불투명도를 조절한다. 기본 최고 높이는 수면 위 3.2이며 모션 강도로 높이를 조절한다. 방울은 실제 움직이는 수면을 기준으로 출발·복귀하고, 들어 올려 마시기 전에 완전히 사라진다. 줄기는 원본 좌표 x=7.5에서 시작해 중앙보다 1만큼 오른쪽인 x=13에 닿는다. 위쪽 곡선의 제어점과 형태는 고정하고, 곡선 뒤의 수직 구간만 수면 높이에 맞춰 짧아지게 해 채워지는 동안 줄기 곡선이 변하지 않는다. 하단 끝점은 둥근 캡의 반경 1만큼 수면 위에 두어 캡 끝이 수면선을 넘지 않게 하며, 잔의 미세한 흔들림도 접촉 위치 계산에 반영한다. 줄기 끝의 둥근 캡이 잔 입구에 처음 닿는 약 0.44초부터 지연 없이 채워지기 시작하며, 1.76초에 원본 수면 높이 y=10까지 차오른다. 첫 수면은 잔 테두리 안쪽의 바닥에서 시작해 채워짐이 바로 드러나도록 한다. 점이 떠 있는 동안에는 잔과 수면을 안정된 상태로 유지하며, 점이 완전히 수면으로 돌아오는 2.28초부터 에어링을 시작한다. 2.28–3.28초에 수면의 부드러운 물결과 잔의 작은 흔들림을 함께 적용한다. 2.96초부터 잔 전체를 기본 1.4만큼 들어 올리고, 3.08–3.72초에 반시계방향으로 40도 기울인다. 3.24–4.16초에는 와인의 양이 줄어 완전히 사라진다. 4.20–4.68초에 빈 잔이 원래 위치와 각도로 돌아온다. 잔이 기울어도 수면은 공간상 수평을 유지하도록 반대 방향의 경사를 적용하며, 수면은 원본 잔 윤곽 안으로 자른다. 원본 수평선은 움직이는 수면으로 교체하고 나머지 잔·줄기·받침 경로는 그대로 사용한다. 선 두께는 2이며, 와인 내부에는 채움 색을 넣지 않고 수면 라인만 표시한다. 시작·끝·정지 상태는 수면이 없는 빈 잔이다. 동작은 `wine-motion.ts`, SVG 연결은 `Wine.tsx`에서 관리한다.

과일은 원본 사과의 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래 → 왼쪽 위 → 양옆의 남은 과육 순서로 둥글게 베어 먹어 심만 남긴다. 첫 입은 애플 로고처럼 오른쪽 위가 둥글게 파이며, 기존 위치에서 원본 좌표 0.8만큼 아래로 내린 위치다. 기본 5초 주기에서 0.50, 1.00, 1.50, 1.95, 2.40, 2.85초에 순서대로 깨물고, 각 입은 0.12초 동안 파인다. 위쪽·아래쪽·중앙의 깨무는 위치를 각각 x=12를 기준으로 좌우 짝을 이루게 배치하며, 각 짝은 같은 높이와 반경을 사용한다. 여섯 번을 순서대로 깨무는 과정만으로 균형 잡힌 심이 남는다. 약 3.0–4.05초에는 꼭지가 붙은 가는 심을 보여준다. 4.05–4.30초에 심이 사라진 다음 잠시 비워 둔다. 4.38–4.72초에 온전한 사과가 위쪽 26만큼 떨어진 위치에서 가속하며 내려와 착지한다. 등장 첫 0.06초에만 짧게 불투명도를 올리고, 이후에는 온전한 모습으로 낙하한다. 착지 후 작은 상하 반동과 함께 오른쪽·왼쪽으로 한 차례씩 흔들린다. 좌우 이동과 기울기가 점점 줄어 4.96초에 원래 위치와 각도로 멈춘 뒤 반복한다. 원본에서 남은 베지어 곡선을 그대로 유지하고, 깨문 원의 안쪽 원호를 이어 윤곽선을 만든다. 여러 입이 겹친 곳에는 바깥에 드러난 원호만 그려 과육 안쪽에 불필요한 선이 남지 않는다. 사과 외곽과 꼭지만 표시하며, 씨를 나타내던 안쪽의 짧은 두 선은 제거한다. 꼭지는 원본 경로를 유지한다. 깨물 때 사과가 작게 반응하며 모션 강도는 이 반응과 착지 반동, 좌우 흔들림의 크기를 조절한다. 시작·끝·정지 상태는 씨가 없는 온전한 사과다. 순서는 `fruit-motion.ts`, 윤곽 계산은 `fruit-shape.ts`, SVG 연결은 `Fruit.tsx`에서 관리한다.

찜·스팀은 국물 아이콘과 동일한 `SteamField`를 사용한다. 찜기 아래 y=17–22에 배치된 원본 세 물결에 중앙 → 왼쪽 → 오른쪽의 순서, 선 사이 간격, 아래에서 위로 올라가는 속도와 위쪽 소멸을 적용한다. 국물과 같은 물결 경로와 선 사이 간격을 사용하며, 찜의 물결은 1.5배 빠르게 흐른다. 약 1.67초마다 다음 물결을 내보내 5초 안에 세 차례 반복한다. 5초 미리보기 내내 흐름이 이어지고 물결 전체가 꺼지는 휴지 구간 없이 반복한다. 점은 표시하지 않는다. 찜기의 뚜껑 선·몸통·받침·세 타공은 원본 경로 그대로 고정한다. 위쪽 손잡이만 원본 중심을 축으로 최대 좌우 12도씩 빠르게 열두 번 회전한 뒤 안정된다. 한 번의 흔들림 구간은 1.8초다. 회전 중심은 원본 손잡이 경로에서 계산하며 현재 (12, 2)다. 2.5초마다 0.44–2.24초 구간에 흔들림이 들어가며, 진폭은 처음과 끝에서 부드럽게 줄어든다. 시작·끝·정지 상태는 원본 자세다. 물결과 손잡이를 포함해 모든 원본 경로를 표시한다. 공통 물결 렌더링과 상태는 `SteamField.tsx`, 손잡이 흔들림은 `steamed-handle-motion.ts`, 찜 아이콘 연결은 `Steamed.tsx`에서 관리한다.

디저트는 체리부터 먹은 뒤 케이크 앞쪽 → 오른쪽 모서리 → 뒤쪽 모서리 → 마지막 조각 순서로 먹고, 마지막 조각도 둥글게 파먹어 없앤다. 온전히 완성된 케이크는 순환 경계 전후를 합쳐 기본 속도에서 1초 동안 유지한다(4.94–5.00초와 다음 주기 0–0.94초). 체리는 0.94–1.12초에 한 입으로 사라지고, 케이크는 1.54, 2.14, 2.74, 3.34초에 0.6초 간격으로 먹는다. 깨물기 자체와 복귀 동작의 속도는 유지하고, 먹는 동작 사이의 대기 시간을 줄여 완성 상태를 더 오래 보여준다. 앞쪽 첫 입의 깊이는 원본 폭의 40%로 두어 초기 29%보다 약 38% 크게 잡았다. 앞쪽과 오른쪽 모서리의 두 입은 모두 원본 윗면을 둥글게 자른 곡선을 케이크 높이만큼 이어 단면을 만든다. 두 절단면의 윗선·아랫선·크림층 두 줄이 같은 곡면을 따라 이어져 양쪽 모두 두께가 보인다. 세 번째 입은 위쪽으로 솟은 뒤쪽 꼭짓점을 둥글게 먹고, 마지막 조각은 3.34–3.90초 동안 윗부분 → 가운데 → 아랫부분으로 둥근 입자국 세 개를 이어 파먹는다. 첫 입은 위쪽 왼편, 다음 입은 오른편의 가운데를 파고들고, 마지막 입은 이미 먹힌 공간에서 아래쪽 남은 조각까지 커진다. 입자국이 생기는 시간을 겹쳐 부드럽게 이어지며, 실제 둥근 외곽과 잘린 케이크 층을 함께 표시한다. 아래로 내려가는 잘라내기 마스크나 층 단위의 순간 삭제는 사용하지 않는다. 새 단면에는 같은 아이콘 색의 옅은 채움을 두어 두께와 잘린 층이 구분된다. 3.90초에 모두 먹고 잠시 비운 뒤, 복귀 때는 깨문 자국이 없는 완전한 층 세 개를 쌓는다. 아래층은 3.98–4.16초, 가운데 층은 4.17–4.35초, 위층은 4.36–4.54초에 위에서 내려와 제자리에 놓인다. 각 층은 원본 윗면 곡선과 실제 두께를 유지하며, 나중에 놓이는 층이 아래층의 가려진 선을 덮는다. 모두 쌓인 뒤 4.56–4.74초에 우측까지 이어진 단면선 두 줄을 원본 끝점 x=16까지 부드럽게 줄인다. 마지막으로 4.76–4.94초에 체리를 위에서 내려놓으며, 체리 아래의 윤곽도 원본처럼 마무리한다. 기본 5초 주기이며 시작·끝·정지 상태는 원본 디저트와 같다. 모션 강도는 먹을 때의 작은 반응을 조절한다. 순서는 `dessert-motion.ts`, 앞쪽과 오른쪽 단면은 `dessert-shape.ts`, 원형 입자국은 기존 `fruit-shape.ts` 계산을 사용한다. 복귀 층 쌓기와 단면선 정리는 `DessertReturn.tsx`, 전체 SVG 연결은 `Dessert.tsx`에서 관리한다.


완두콩은 개별 미리보기에서만 5초 모션을 재생하며, 그리드 영상에서는 내부 콩 두 알이 보이는 원본 기본 아이콘으로 고정한다. 안쪽 선이 없는 콩깍지 → 원본 콩 지름 길이의 대각선 직선 → 뾰족한 럭비공 → 원의 네 단계는 유지하되, 각 콩이 입구를 안에서 밀어 올리면서 빠르게 벌리고 바로 튀어나온다. 첫 입구는 0.18–0.40초에 선을 드러내고 0.50–0.70초에 럭비공, 0.70–0.80초에 원으로 열린다. 콩과 입구가 함께 원본 좌표 0.35만큼 위로 밀리고, 아직 열리는 중인 0.76초에 콩이 위로 튀어나오면 입구는 0.16초 동안 제자리로 돌아온다. 두 번째 콩과 입구는 같은 동작을 0.18초 늦게 수행한다. 콩은 나오기 전까지 입구 모양으로 가려져 있으며 등장·퇴장 페이드는 없다. 출발 위치를 이어 받아 중력 포물선으로 낙하한 뒤 작은 바운스를 두 번 하고 오른쪽으로 굴러 3.65초까지 아이콘 원본의 24 × 24 설계 경계를 벗어난다. 콩 선의 바깥쪽은 설계 그리드 하단 y=24에 닿고, x=24를 넘는 부분부터 잘려 사라진다. 2.80초부터 두 알에 같은 추가 이동량을 적용해 간격을 유지한다. 3.72–4.15초에는 원 → 럭비공 → 선으로 닫히고 4.15–4.45초에 내부 선도 사라진 뒤 시작 모습으로 쉰다. 개별 미리보기 크기에 관계없이 같은 설계 경계와 5초 주기를 사용한다. 원본 콩깍지 외곽과 콩 두 알의 경로·크기, 선 두께 2를 유지한다. 모션 강도는 입구를 밀어 올리는 높이와 팝·바운스 높이를 조절한다. `pea-motion.ts`에서 시간·곡선·궤적을 계산하고 `Peas.tsx`에서 렌더링한다.

### 그래프 전환 내부 재사용 · 2026-10-12

`TasteGraph-Transition`은 볶음(웍)·디저트(케이크)·와인의 원본 기본 SVG를 `animate={false}`로 세 버블 안에 표시한다. 버블 유지와 파이 전환 중에도 아이콘 내부 모션은 재생하지 않는다. `FoodIcon.clock`으로 로컬 `frame`·`fps`를 전달하면 기존 `WokFrame`·`DessertFrame`·`WineFrame` 렌더링을 사용한다. 개별 영상과 그리드는 기존 Remotion 시계를 그대로 쓰며 원본 모션 함수·속도·강도·SVG 기하는 바꾸지 않는다.
