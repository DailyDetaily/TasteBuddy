# 보관된 다이나믹 버전

2026-09-22: 사용자 요청으로 `LogoGrid-Dynamic` 및 `LogoGrid-Dynamic-HD`를 Studio 등록에서 제거했습니다. 현재 별도 로고 애니메이션은 가이드 없는 `Logo-Black` / `Logo-Black-HD`입니다. 아래 내용과 Dynamic 소스·출력은 이전 버전 기록입니다.

Logo Grid — 원본과 Dynamic 버전

두 버전은 `01-Original`과 `02-Dynamic` 폴더에 분리되어 있습니다. 2026-09-22 요청으로 두 버전 모두 쇼츠의 꽃잎 펼침과 역재생 접힘을 사용합니다. 제공 SVG와 참조 MP4, 쇼츠 소스는 보존하며 변경 전 Grid 코드와 4K 영상은 `output/logo-grid-shorts-opening-20260922/before`에 보관했습니다.

| 버전 | Studio | 출력 |
|---|---|---|
| 원본 재현 | http://localhost:3110/LogoGrid | `output/logo-grid/TasteBuddy-LogoGrid-4K.mp4` |
| Dynamic | http://localhost:3110/LogoGrid-Dynamic | `output/logo-grid-dynamic/TasteBuddy-LogoGrid-Dynamic-4K.mp4` |

두 버전 모두 3840×2160, 30fps, 10초입니다. 각각 HD 컴포지션도 있습니다. `LogoGrid-Reference`는 제공된 MP4를 보여주는 별도 참조용 컴포지션입니다.

Dynamic은 중앙 12원부터 위쪽으로 원을 확대하고, 여섯 SVG 잎을 3D 원근 공간에서 펼친 뒤 글자와 전체 로고로 시선을 이동시킵니다. 원은 모두 채움 없이 윤곽선으로 표시합니다. 로고 본체는 원본 SVG 경로를 사용합니다.

| 시퀀스 | 시간 | 연출 |
|---|---|---|
| 01 | 0.0–0.7초 | 중앙 12원에서 시작, 바로 위 6원으로 연결 |
| 02 | 0.7–1.8초 | 14→28→38원까지 위쪽으로 확대, 중앙 12원 유지 |
| 03 | 1.8–2.9초 | 여섯 잎을 펼치며 중앙 12원을 포함한 초반 치수 가이드는 위에 유지 |
| 04 | 2.9–3.8초 | 주변 작도 원이 확대되며 초반 보조 치수 가이드는 정리 |
| 05 | 3.8–4.8초 | 심벌에서 로고타입으로 오른쪽 이동 |
| 06 | 4.8–6.1초 | Taste, Buddy 순으로 둥근 세리프 끝에서 획 안쪽으로 컬러 채움 |
| 07 | 6.1–7.5초 | 전체 로고로 이동하면서 정렬·치수선 공개 |
| 08 | 7.5–10.0초 | 가이드 제거 → 로고 유지 → 269–299프레임에서 펼침 역재생, 흰 화면으로 마무리 |

원의 등장 순서는 **12→6→14→28→38**입니다. 각 원의 하단을 고정하고 원 전체를 0%→100%로 확대하며, Ease Out으로 초반에 빠르게 자라고 끝에서 감속합니다. 선을 따라 그리는 dash 애니메이션과 회색 채움은 제거했습니다. 카메라는 중앙에서 위로 따라가며, 원과 심벌의 화면상 방향은 원본의 수직 정렬로 고정합니다.

꽃잎은 쇼츠 `TasteBuddy-Petal-Shorts`의 첫 X축 펼침과 같은 모션을 사용합니다. 여섯 잎이 심벌 중심 `(308,249)`을 공통 기준점으로 로컬 X축 90°→0°를 동시에 회전하며, 30프레임/1초 Easy Ease입니다. 꽃잎 자체의 크기·투명도·색은 고정하고 그리드 원본 경로와 색 `#E1E1E1`을 유지합니다. 원근 거리는 쇼츠와 심벌 반지름의 비율이 같도록 환산합니다. 펼침 구간에는 중앙 12원과 6·14·28·38 원 및 숫자를 심볼 위에 유지합니다. 중앙 12원·숫자와 38원의 윤곽은 끊김 없이 다음 장면으로 이어져 225–246프레임의 공통 가이드 정리와 함께 사라지고, 나머지 초반 치수 원·숫자는 87–99프레임에 사라집니다. 심벌의 화면상 방향과 카메라 기울임은 고정합니다.

접힘은 별도 곡선 없이 펼침 프레임을 30→0으로 역재생합니다. Dynamic은 269–299프레임에 꽃잎을 접고 로고타입을 함께 정리합니다. LogoGrid는 기존 퇴장 구간인 228–258프레임에 동일한 접힘을 적용합니다.

카메라 배율은 최종 구도를 1.0×로 정의합니다. 중앙 12원을 보여주는 22× 클로즈업에서 시작해 위쪽 원들을 따라 축소하고, 심벌 구간은 2.65→1.75×로 움직입니다. 최종 로고 외곽은 화면 가로 약 62%를 차지합니다. 작도선은 카메라·원 확대에 맞춰 두께를 보정합니다.

8개 장면의 연출 타이밍과 카메라 키프레임은 유지합니다. Studio 타임라인은 2026-09-22 요청에 따라 장면 묶음에서 실제 요소 82개를 기능별 **21개 레이어**로 묶었습니다. 기존에 제외된 하단 6원과 숫자 2개는 추가하지 않습니다. 카메라는 글로벌 프레임을 사용하고, 각 묶음은 독립 클립의 로컬 프레임을 사용하며 내부 요소의 등장 간격을 유지합니다. 246–268프레임에 완성 로고를 유지한 뒤 역재생 접힘으로 마무리합니다.

구현 파일:

- `LogoGridDynamic.tsx`: 다이나믹 레이어 장면 연결.
- `DynamicLayers.tsx`: 실제 등장 구간에 배치된 21개 기능별 묶음의 편집 가능한 타임라인.
- `DynamicElementArtwork.tsx`: 요소별 등장·작도·마스킹과 카메라 배치.
- `GridLayer.tsx`, `layerTiming.ts`: 공통 편집 레이어와 원본 모션 시간, 심볼 최하단 합성.
- `dynamicMotion.ts`: 장면별 길이와 연속 카메라 키프레임.
- `PetalBloom3D.tsx`: 두 Grid에서 공유하는 원본 SVG 면의 원근·X축 회전.
- `shortsOpening.ts`: 쇼츠 펼침 함수 재사용, 크기별 원근 환산, 원본 Grid의 펼침·접힘 타이밍.
- `index.tsx`: 원본/다이나믹 폴더 및 4K/HD 컴포지션 등록.

`brand-launch`에서 실행:

```sh
node scripts/render-logo-grid.mjs --dynamic
node scripts/render-logo-grid.mjs --dynamic --video
node scripts/render-logo-grid.mjs --dynamic --video --hd
node --test scripts/logo-grid-dynamic.test.mjs
```

`--dynamic`이 없는 기존 명령은 원본 재현 버전을 대상으로 합니다. 새 버전의 렌더 파일은 `output/logo-grid-dynamic`에 저장하므로 기존 결과를 덮어쓰지 않습니다.

이번 비교 프레임과 검증 결과는 `output/logo-grid-shorts-opening-20260922`에 기록합니다. 이전 2026-09-17 Dynamic 개정 사본도 `output/logo-grid-dynamic/revisions/before-petal-bloom-20260917`에 유지합니다.

타임라인 위→아래: 치수·주석 / 가이드선 / 작도 원 / 로고타입 / 심볼. 가이드선은 함께 움직이는 5개 기준선 묶음으로 정리하고 원과 숫자는 짝을 유지합니다. 로고타입은 Taste/Buddy 두 클립, 여섯 꽃잎은 심볼 한 클립입니다.

로고타입 진입은 원본 글자의 둥근 끝에서 시작하는 획 내부 거리 마스크를 사용합니다. 획 두께를 따르는 원형 브러시로 채움의 선두를 둥글게 처리합니다. Taste는 126–158프레임, Buddy는 150–182프레임에 완성되며 글자별 24프레임, 2프레임 간격입니다. 글자 자체의 이동·압축·진입 페이드는 제거했고, 원본 글자색과 외곽·내부 여백을 유지합니다.

세리프 원 가이드: 둥근 끝부분 28곳의 원이 해당 글자 채움과 동시에 나타납니다. Taste 126프레임, Buddy 150프레임부터 글자별 2프레임 간격, 24프레임 동안 같은 진입 이징을 공유합니다. 원 내부 숫자는 지름 종류별 가장 왼쪽 원에 하나씩만 표시합니다. 5·6·7·8·11·12의 6개 숫자를 남기며 같은 x좌표에서는 위쪽 원이 우선입니다. 기존 중복 숫자 경로 51·73은 렌더하지 않습니다. 원형 가이드의 위치·크기·선 두께와 한 레이어 묶음은 유지하고 225–246프레임에 퇴장합니다.

심볼은 독립 합성 영역의 z-index -1 평면으로 내려, 정지 상태와 3D 펼침·접힘 모두 원형 가이드·숫자보다 아래에 합성합니다.

초반 가이드 수정: 6·14·28 원의 실제 타임라인 종료를 54에서 99프레임으로 늘렸습니다. `introVisibility()`와 `DynamicElementArtwork.tsx`는 초반 원을 3D 펼침 숨김 조건보다 먼저 처리하므로 펼침 도중 누락되지 않습니다. 중앙 12원·숫자의 타임라인 종료도 246프레임으로 늘려 54프레임의 펼침 진입에서 사라지지 않습니다. 38원은 87프레임에 다시 0% 크기로 시작하지 않습니다.

직선 그라데이션 가이드 16개는 공통 중심색 `#C0C0C0`과 선 불투명도 100%를 사용합니다. 기존 `#808080`의 50% 수준 밝기를 색상 자체로 적용해 좌우 외곽 세로선과 내부선을 통일했습니다. 끝부분 페이드와 카메라 배율에 따른 기존 선 두께 보정은 유지하며, 공통 색상은 `guideStyle.ts`에서 조절합니다.
