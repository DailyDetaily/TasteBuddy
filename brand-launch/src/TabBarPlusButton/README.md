# TabBar-PlusButton

Editable Remotion composition at `http://localhost:3110/TabBar-PlusButton`, in the `App-UI` folder.

- 1080 × 1080, 60fps. Six 3.6-second color cycles, followed by a matching terminal frame (1297 frames at speed 1).
- Inspector controls: playback/freeze, normal/pressed appearance, button diameter, speed, starting color pair, glass strength, and background color.
- Defaults are declared directly in `Root.tsx` so the installed Remotion Studio can save them.
- Motion is frame-driven and deterministic. No wall-clock timers, CSS animation, or runtime randomness.

The native reference is `ios/TasteBuddy/Components/Shell/BottomTabCenterButton.swift`: 48pt geometry, eight gradient blobs, three motion groups, hue/saturation/luminance calculations, 3.6-second cycle, icon geometry, and the verified one-pixel color inset at @3x. The six native palette colors are arranged into a repeatable sequence for video.

The optical surface is an SVG/CSS approximation calibrated against the iPhone screenshots from `output/qa/tab-center-glass-20260929/`. Chromium does not execute SwiftUI's native `glassEffect`. This port is editable source, not an iOS screen recording or an automatic native-source sync.

Validation:

- `npm run lint` (ESLint + TypeScript)
- `node --test scripts/plus-button.test.mjs`
- `node scripts/render-plus-button-stills.mjs`
- Live Studio playback and Inspector display

Renders and Studio evidence are saved in `brand-launch/output/tabbar-plus-button/`. The still renderer verifies identical PNG hashes at frames 0 and 1296, and exports intermediate frames, a native-scale still, and a pressed-state still. A full MP4 export is not generated by that verification command.
