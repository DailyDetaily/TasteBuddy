# 테이스트 블룸 · 형태에 근거한 36종 명명 규칙 제안

상태: 명명 규칙 제안. 현재 미리보기의 이름과 모션에는 적용하지 않았다.

## 기준

현재 기본 형태는 **꽃잎 4종 × 수술 3종 × 암술 3종 = 36종**이다.
바깥 잎과 중간 잎은 같은 꽃잎 유형을, 두 수술 레이어는 같은 수술 유형을 공유한다.
이름은 이 세 가지 실제 도형 속성을 순서대로 표현한다.

**이름 = 꽃잎 계열 + 수술 + 암술**

예: **캡슐 레이 젬** → 캡슐형 꽃잎 + 끝이 둥근 방사선 + 마름모 암술.

단어는 새로 제안한 명명 약속이다. 각 단어의 근거는 현재 SVG 기하이며,
실제 꽃 종, 맛의 성질, 사용자 성격에 대응한다고 주장하지 않는다.

## 단어와 관찰 근거

| 요소 | 명칭 | 실제 코드 값 | 확인 가능한 기하 |
| --- | --- | --- | --- |
| 꽃잎 | 라운드 | `roundPetal` | 잎 하나를 `circle`로 그림 |
| 꽃잎 | 캡슐 | `capsulePetal` | 길쭉하고 양끝이 둥근 `rect`; 너비의 절반을 모서리 반지름으로 사용 |
| 꽃잎 | 다이아 | `softDiamondPetal` | 위아래 끝이 뾰족하고 네 변이 곡선인 마름모형 path |
| 꽃잎 | 크라운 | `serratedTipPetal` | 잎 바깥 끝에 세 개의 봉우리와 두 개의 홈이 있는 path |
| 수술 | 스타 | `thinStamen` | 바깥·안쪽 반지름을 번갈아 연결한 가는 별 모양 polygon |
| 수술 | 레이 | `roundedSpokeStamen` | 끝이 둥근 개별 방사선 path의 반복 |
| 수술 | 비드 | `dottedRayStamen` | 각 방사선 끝에 작은 원이 하나씩 있는 line + circle 조합 |
| 암술 | 도트 | `solidPistil` | 중심의 원 한 개 |
| 암술 | 젬 | `diamondPistil` | 중심의 정사각형을 45도 돌린 마름모 한 개 |
| 암술 | 시드 | `seedCluster` | 가운데 작은 원과 주변의 작은 원 4~6개가 이루는 군집 |

‘다이아’는 꽃잎 외곽, ‘젬’은 암술에만 쓴다. ‘비드’는 방사선 끝의 점,
‘도트’는 가운데 원 하나, ‘시드’는 가운데 원 군집을 가리킨다.
같은 원형 요소라도 위치와 배열을 함께 지정해 혼동을 줄인다.

## 적용 규칙

1. 같은 세 가지 형태 값에는 항상 같은 이름을 부여한다. 재생 순서와 무관하다.
2. 세 요소 중 하나가 바뀌면 그 요소에 해당하는 단어만 바뀐다.
3. 색 배치·취향 수치·크기·잎 개수·펼침 각도는 36종 기본 이름에 포함하지 않는다.
4. 잎 개수가 필요하면 `라운드 스타 도트 · 6잎`처럼 별도 변형 정보로 표시한다.
   잎 개수까지 구분할 때만 36 × 5 = 180종으로 확장한다.
5. 색 변화와 접힘·펼침만으로 이름을 바꾸지 않는다. 현재 순환 모션은 접힌
   상태에서 세 가지 형태 값이 바뀌므로, 그 교체 시점에 다음 이름을 표시한다.
6. 명칭에서 세 요소를 모두 복원할 수 있어야 한다. 명칭에는 생략형을 두지 않는다.
7. 내부 식별자는 `petalShape / stamenShape / pistilShape`의 조합을 사용한다.
   화면의 01~36은 재생 순서이며, 이름이나 형태의 영구 식별자로 쓰지 않는다.
8. 기존 ‘데이지·로제트·마가렛’ 등에 새 규칙의 근거를 소급해서 붙이지 않는다.
   현재 이름은 기존 별칭으로 기록하고, 규칙 채택 시 새 이름과 대응시킨다.

## 검증 기준과 범위

- 가능한 세 요소의 조합 36개를 빠짐없이 포함하고, 중복 이름이 없어야 한다.
- 이름 → 세 요소 → 이름의 변환이 일치해야 한다.
- 색·크기·잎 개수·모션 상태가 달라도 세 요소가 같으면 이름이 같아야 한다.
- 실제 완전히 펼쳐진 SVG에서 각 명칭의 기하 근거를 확인할 수 있어야 한다.

현재 제안의 근거는 코드상의 도형 정의다. 이름의 기억 용이성이나 사용자 선호는
별도 검증 대상이다. 짧은 한 단어였던 기존 이름보다 길지만, 36종 모두의 차이를
같은 규칙으로 읽고 설명할 수 있게 한다.
