# 소스 스플래터 · Sauce Splatter

Studio의 `Chip-Motion → Sauce-Splatter`에서 칩 등장 모션만 확인한다.
[Studio 열기](http://localhost:3110/Sauce-Splatter)

- 1080 × 1080 정사각형, 60fps. 음식 종류 24개를 **5줄(5·5·5·5·4개)**로 배치한다. 기본 확대 배율은 5이며, 실제 배율은 위아래 72px 여백을 남기는 약 4.42다. 칩 높이는 화면에서 약 159px로 고정하고 줌아웃하지 않는다. 양옆 칩 일부는 화면 밖으로 이어진다. 문구는 제품의 `src/constants/dishKindTags.ts` 분류를 따른다.
- 각 칩의 크기와 글꼴은 네이티브 `TBSelectableChip(.dining)` / `ChipSize.medium` 규격을 사용한다. 원본 단위는 높이 36, Pretendard Medium 12, 아이콘 16, 아이콘–문구 간격 6, 좌우 패딩 12, 세로 패딩 8, 테두리 1, 칩·행 간격 8이다. 전체 화면 배율만 별도로 적용한다.
- 아이콘은 `src/constants/dishKindIcons.ts`의 SVG이며, 24개 모두 실제 iOS `DishKind-*.imageset` 파일과 도형·속성을 대조한다. `아이콘`에서 음식 종류 ID를 선택하거나 `자동`(문구로 연결), `없음`을 고를 수 있다. 아이콘과 문구는 함께 등장하고, 연결·분리 중에도 비율을 유지한다.
- 각 줄 안에서 칩이 연결·분리되고, 다음 줄은 0.65초 뒤에 시작한다. 시작 대기 0.4초, 유지 1.5초이며 전체 길이는 줄 수와 속도에 맞춰 계산한다.
- 독립 화면의 분리는 소스를 뿌리는 느낌으로 조절한다. 다음 원이 빠져나오는 시간은 180ms에서 120ms로, 연결부가 가늘어져 끊어지는 구간은 120ms에서 55ms로 줄인다. 연결부는 160ms까지 늘어난 뒤 빠르게 끊어지며, 캡슐 확장·오버슛·안착·다음 칩 시작·행 간격은 기존 타이밍을 유지한다. 카메라 경로와 정지 시점도 같다. 이 옵션을 전달하지 않는 기존 식사 피드백 화면은 원래 분리 동작을 사용한다.
- 카메라는 첫 칩 왼쪽에 기본 80px 여백을 두고 시작한다. 각 줄은 같은 왼쪽 기준선에서 출발하며, **세 번째 줄의 첫 칩이 캡슐로 확장될 때까지 고정**한다. 그 이후 최종 위치까지 한 번에 오른쪽으로 이동한다. 1–2줄이면 마지막 줄의 첫 칩을 기준으로 한다. 중간 정지나 끝부분의 추가 이동 없이 가장 긴 줄 오른쪽에 80px 여백을 남기고 정지한다.
- 최종 카메라 위치는 실제 측정한 전체 칩 너비로 결정한다. 시작부터 종료까지 하나의 smootherstep 곡선을 적용하여 한 번 가속하고 한 번 감속한다. **카메라가 먼저 정지하고 0.35초 뒤에 마지막 칩이 완성**된 다음 설정한 유지 시간을 갖는다(속도 1 기준). 경과 시간만으로 위치를 계산하므로 프레임 탐색과 영상 렌더가 동일하다. 기본 영상 길이는 395프레임(약 6.58초)이다.
- 문구와 아이콘, 선택 상태, 칩 개수(1–24개), 줄 수(1–8줄), 속도, 시작 대기, 유지 시간, 확대 배율, 상하 여백, 카메라 여백을 Props에서 바꾼다. 각 줄의 개수 차이는 최대 1개이며 입력 순서를 유지한다. `정지`는 카메라 이동까지 마친 완성 상태다. 배경은 흰색이다.
- 기본 미선택 상태는 배경 `#F7F7F7`, 아이콘·문구 `#535353`, 테두리 `#E7E7E7`이다. `선택`을 켜면 네이티브처럼 배경·테두리 `#0F0F0F`, 아이콘·문구 `#FFFFFF`가 된다. 미각 틴트는 적용하지 않는다. 긴 문구도 실제 폰트와 아이콘 너비로 측정하며 화면 가장자리에서 잘릴 수 있다.
- 반복 확인은 Studio의 Loop 재생을 사용한다. 별도의 퇴장 모션은 포함하지 않는다.
- 기본 Props는 [`Root.tsx`](../Root.tsx)의 인라인 객체로 관리하여 Studio에서 변경값을 저장할 수 있다.

식사 피드백의 [`MetaballChipRow`](../DiningFeedbackMotion/MetaballChipRow.tsx), [`chip-motion.ts`](../DiningFeedbackMotion/chip-motion.ts), [`ResultChip`](../DiningFeedbackMotion/ResultChip.tsx)을 재사용한다. 원 → 캡슐, 가로 오버슛과 높이 압축, 다음 원의 연결·분리, 라벨 비율과 완성 크기는 [모션 시스템 계약](../../../docs/design/motion-system.md#소스-스플래터--sauce-splatter)을 따른다. 이 컴포지션은 아이콘 콘텐츠·행 배치·경과 시간·화면 배율을 조절한다.

칩 문구는 모션 확인용 예시이며 계정 데이터나 분석 결과가 아니다. 이번 범위는 Remotion Studio이며 웹·네이티브 제품 통합은 포함하지 않는다.

검증: `node --test scripts/sauce-splatter-native-chip.test.mjs scripts/chip-metaball.test.mjs scripts/sauce-splatter-camera.test.mjs scripts/sauce-splatter-separation.test.mjs`. 현재 Swift에서 규격과 색상 역할을 읽어 사용 토큰을 검증하고, 네이티브 fixture의 24개 라벨·SVG 도형·폰트 파일 및 기존 결과 칩의 비변경을 확인한다. 카메라의 시작·종료 여백, 전진 추적, 정지, 임의 프레임 탐색도 검사한다. 분리 옵션은 빠른 연결부 해제와 기존 성장·안착 타이밍 및 다른 호출자의 원래 경로를 확인한다. 이는 소스·에셋 대조와 Remotion 검증이며 실제 기기 화면의 픽셀 비교를 의미하지 않는다.
