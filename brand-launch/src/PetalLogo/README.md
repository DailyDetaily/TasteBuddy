## 미리보기에서 직접 편집

- **레이어 길이:** 타임라인 막대의 끝 손잡이(`Drag to change duration`)를 좌우로 드래그한다. 시작점은 시작 쪽 트림 손잡이로 조절한다.
- **키프레임 위치:** 레이어 오른쪽 화살표(`Expand track properties`)를 누른 뒤, 속성 행의 다이아몬드 키프레임을 좌우로 드래그한다.
- **키프레임 값:** 펼친 속성 행의 회전 각도·단축 진행·두께 값을 수정할 수 있다.
- **실행 취소:** ⌘Z. 타임라인 편집은 `PetalLogo.tsx`에 저장되어 새로고침과 영상 렌더에도 적용된다.
- **색·배율·중앙 여백·전체 영상 길이:** 오른쪽 Props 패널에서 수정한다. 타임라인을 전체 영상 길이보다 길게 쓰려면 `영상 길이`도 늘린다. 30프레임은 1초다.

일반 `npm run studio`로 실행한다. `studio:categories`의 `--disable-interactivity` 옵션은 이 버전에서 타임라인 드래그를 비활성화한다.

## 기하

첨부 `Symbol(꽃잎).svg`의 원본 path를 앞·뒷면에 그대로 사용한다. 심볼 중앙은 `(540,960)`으로 고정한다. 원본 SVG 좌표의 X축으로 펼치고, 각 꽃잎의 로컬 Y축으로 회전한다. 두께 10은 영상 논리 좌표에서 앞면 Z=+5와 뒷면 Z=−5의 거리다. 88개의 옆면이 곡선 외곽을 연결한다.

12개 라인은 원본 6개와 복제본 6개로 구성되며 기본값에서 각도 간격은 30°다. 단축은 전체 그림 확대나 중앙 원 마스크가 아니다. 원근 투영 후 각 라인의 바깥 끝을 기준으로 방사 방향의 길이만 줄인다. 가로 두께·배치 각도는 그대로다. 원본 곡선의 투영 극값에서 바깥/안쪽 반지름을 구하며, 기본값에서 바깥 반지름은 약 334.4213, 최종 안쪽 반지름은 83.6053으로 정확히 1/4이다.

기본 배경은 흰색, 심볼은 #0F0F0F, 불투명도는 100%다. 원본 SVG 사본의 #E1E1E1은 수정하지 않았다. 프레임 기반 계산으로 역방향 탐색과 병렬 렌더가 재현된다.

분석 구간의 초반은 중앙에서 확대 → 위로 이동하며 축소 → 위에서 확대 → 오른쪽 아래로 이동하며 축소 순서다. 위쪽/도착 위치는 기존 `analysisCircle()`의 기준점을 사용한다. 분석 시계 1.5초 이후의 이동·반지름은 기존 `taste-motion.ts`의 `analysisCircle()` 경로를 그대로 사용한다. 선 수와 색은 현재 로고의 12개·단색을 유지한다. `analysisGeometry.ts`의 좌표 계산으로 SVG 직선의 끝점을 정한다. 각 선은 이동하는 내부 원의 중심을 향하고, 끝 단면은 선에 수직이며 두께는 유지된다. 전단 변형이나 새 선으로의 교체는 사용하지 않는다. 시작과 끝의 중앙 복귀 및 분석 진행 키프레임에 Easy Ease를 적용한다. `분석 움직임 진행 (초)` 키프레임도 Studio에서 편집할 수 있다.

조정 구간은 기존 `rotatingLayers`의 3층 각도 순서를 `adjustmentGeometry.ts`에서 3초로 재생한다. 12개 SVG 직선을 각각 3개의 같은 길이로 나누어 총 36개의 직선을 사용한다. 각 조각은 직선 형태로 회전하며 굽히지 않는다. 마지막에는 모든 층이 +30°에서 다시 정렬된다. 각 단계와 편집 가능한 진행 키프레임은 Easy Ease를 사용한다. 시작/완료 프레임에는 분할되지 않은 12개 SVG 직선을 그린다.

피드백 구간은 기존 `feedbackMorph`의 회전→굽힘 순서를 사용한다. 36개 2D 중심선을 굽혀 직선에서 원호로 이어지게 한다. 원호가 완성되면 SVG circle 3개로 그려 이음매와 불필요한 면을 제거한다. 1.7초 전환이 완료되면 별도의 루프 레이어로 이어진다. 루프는 원이 바깥으로 퍼져 희미해지고 안쪽에서 이어 나타나는 3초 주기를 한 번 재생한다. 개별 원은 불투명도 0인 순간에만 반지름을 되돌린다. 전환 시작 심볼에는 페이드를 추가하지 않는다. 각 루프의 시작/끝 배치와 불투명도는 동일하며, 전환/루프 진행 키프레임과 레이어 길이를 각각 편집할 수 있다.

## 구현

- `PetalLogo.tsx`: 공개 `Interactive.withSchema` API로 등록한 편집 레이어. `from`, `durationInFrames`, `interpolate()` 키프레임은 Studio가 읽고 수정할 수 있는 JSX 값이다. 커스텀 컴포넌트의 `componentIdentity`는 `null`로 두어 소스 위치를 해석한다.
- `PetalSolid.tsx`, `solidGeometry.ts`: 원본 곡선, 두께, 옆면, 투영 후 반지름 계산.
- `settings.ts`, `index.tsx`: Props 편집 폼과 컴포지션 등록.
- `motion.ts`: 기본 타이밍과 기하 검증용 순수 함수. 실제 타임라인 편집 결과는 `PetalLogo.tsx`의 키프레임/레이어 값이 기준이다.
- `public/brand/petal-logo/source.svg`, `source.ts`: 원본 사본, path 및 SHA-256.

## 2D 라인 렌더러

Y축 회전 이후 04–14 레이어는 `renderMode="lines"`로 지정한다. `PetalLines.tsx`가 복제·단축·분석·조정·역재생을 6/12/36개 SVG 직선으로 표시한다. 선 두께는 기존 두께 값(기본 10), 색은 기존 면의 표시 색을 따른다. 원본 심볼의 투영 반지름은 시작 크기를 맞추는 정적 계산에만 사용하고, 매 프레임 3D 면이나 원근 변환은 생성하지 않는다. 피드백은 `PetalFeedback.tsx`의 36개 원호 경로 또는 3개 원으로 표시한다.

01–03의 꽃잎 펼침·Y회전 및 15–17의 심볼 복원·X축 접힘은 기존 3D 기하를 사용한다. 모든 사용자 편집 타이밍과 키프레임은 변경하지 않았다(`2d-timing-check.json`).

2026-09-21 타임라인 정리: 피드백 역재생의 마지막 키프레임은 440F, 라인 길이 복원은 441F부터 시작한다. 뒤 구간을 1F씩 이동하여 동시 표시를 제거했다. 접힘 완료 481F부터 15F(0.5초)만 유지하고 전체 영상을 496F에 종료한다.
