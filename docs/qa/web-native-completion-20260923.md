# 네이티브 → 웹 이식 잔여 작업 결산 — 2026-09-23

**기존 보고서에 남겼던 로컬 구현 항목을 반영했고, 웹·Swift 계약·네이티브 계정·네이티브 UI 검증을 완료했다.** 실서비스 로그인 계정으로 두 기기를 왕복한 결과나 운영 배포 완료를 뜻하지 않는다. 전체 화면의 모든 기기·글자 크기·사진 포맷에서 픽셀이 같다는 보증도 하지 않는다.

## 검증 범위 밖인 항목

- 운영 Supabase 함수 배포와 실제 로그인 계정의 웹→iOS→웹 왕복은 실행하지 않았다. 수정된 함수가 아직 배포되지 않아도 웹의 ID 재검증이 잘못된 장소 연결을 막는다.
- 실제 카메라·GPS, 모든 브라우저의 사진 디코더/크롭 제스처, VoiceOver의 전 화면 조작, 모든 Dynamic Type 크기에 대한 비교는 이 결과에 포함하지 않는다. 지원하지 않는 사진 형식은 원본을 보존하고 안내한다.
- 현재 카탈로그나 provider에서 확인할 수 없는 식당 ID는 미확인 상태로 유지한다. 이름이 같다는 이유로 대응표를 만들지 않는다. 조회·소유자 확인·재시도 흐름의 구현과 존재하지 않는 외부 데이터의 확보는 구분한다.
- 북마크 pending 전용 네트워크 호출은 현재 네이티브에도 활성 경로가 없어 임의로 추가하지 않았다. 전체 계정 snapshot과 함께 대기 이력을 보존한다.
