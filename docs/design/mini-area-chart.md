# 미니 영역 차트

2026-10-07 · 미니 라인 그래프 바로 아래에 추가한 영역 차트 컴포넌트.

값을 직선으로 연결해 그래프 바닥까지 불투명 `taste/{axis}/tint/60` 색으로 채운다. 컨테이너의 최대 높이는 56px이며 캡슐 윤곽, 얇은 라인, 현재·과거 노드는 표시하지 않는다. 양끝과 하단 모서리는 R 6을 유지한다. 중간 상단 꺾임은 인접한 변 양쪽으로 최소 6px를 둥글게 연결해 양끝과 비슷한 둥근 인상을 만든다. 인접한 변이 짧으면 라운드 구간을 각 변 길이의 절반으로 제한한다.

- 컨테이너: 132 × 56px, 내부 행: 56px, 위아래 여백: 0px.
- 색: `chart/tint/60` (Light: 일반 tint/60, Dark: 일반 tint/10). 감칠맛은 Light `#E1C7E1` / Dark `#A469A5`다. 배경용 틴트와 구분한다.
- 여러 계열은 공통 척도와 4px 행 간격을 사용한다. 단일·겹침·비교 모두 값 0은 높이 0px, 값 1은 12px다. 56px 행에서 값 1 초과는 `12 + (값−1)/(공통 최댓값−1) × 44`로 높이를 계산한다. 여러 행으로 높이를 나누면 44 대신 `행 높이−12`를 사용한다. 모든 값이 1 이하면 56px로 확대하지 않는다. 0~1 값은 0~12px로 선형 보간한다.
- 하단 경계는 56px 그래프 행 바닥이자 알려진 0의 기준선이다. 1의 고정 높이를 포함하는 표현 척도이므로 면적을 기록 총량으로 해석하지 않는다.
- 최근 데이터 선택은 `TasteLineChart`의 기존 로직을 공유한다. `area` 옵션에서 높이·직선 면·척도를 적용한다.

```tsx
<MiniAreaChart entries={[
  { id: 'umami', taste: '감칠맛', values: [1.2, 2.1, 2.4, 4.5] },
]} label="최근 감칠맛 변화: 1.2, 2.1, 2.4, 4.5" />
```

[플레이팅 예시](/design-system/components/mini-area-chart). 미니 그래프 및 미니 라인 그래프 페이지에서도 라인 예시 바로 아래에 배치한다. 예시 데이터는 합성 값이다. 웹·iOS 제품은 아카이브의 실제 계정 기록을 집계해 연결한다. [데이터 계약](data-component-contract.md)을 따른다.

## 겹침과 같은 미각 비교

`variant="layered"`는 서로 다른 미각을 최대 3개까지 같은 132 × 56 영역에 겹친다. 각 미각의 불투명 차트용 `tint/20`을 사용하며, 큰 면부터 뒤에 그린다. `variant="comparison"`은 같은 미각의 두 계열이다. 채워지는 면적이 큰 계열은 캡슐과 같은 `chartTrack`(Light 일반 tint/80 · Dark 일반 tint/70), 작은 계열은 차트용 `tint/20`이다. 현재·이전 구분과 색 농도는 고정 관계가 없으므로 범례에 기간을 함께 표시한다.

새 두 구성은 같은 길이의 날짜 슬롯, 공통 0 기준선과 공통 최댓값을 사용한다. 최근 4개 슬롯을 표시하고 값을 누적하거나 계열별로 따로 정규화하지 않는다. `null`·음수·비정상 값은 미확인으로 다루며 사이를 연결하지 않는다. 알려진 0은 바닥에 남는다. 공통 표시 높이로 계산한 사다리꼴 면적이 큰 순서로 그리되 입력 값과 교차하는 위치를 바꾸지 않는다. 라운드는 양끝 R 6과 중간 모서리의 6px 시각 보정을 함께 적용하며 짧은 변에서 제한한다. 미확인 구간으로 나뉜 면은 각 조각의 양끝을 기준으로 판단하므로 데이터 경계를 중간 꺾임처럼 과하게 둥글리지 않는다. 겹쳐 가려지는 면적을 합계로 해석하지 않는다.

```tsx
<MiniAreaChart variant="layered" entries={[
  { id: 'umami', taste: '감칠맛', values: [4, 6, 7, 10] },
  { id: 'sweet', taste: '단맛', values: [2, 3, 4, 6] },
  { id: 'bitter', taste: '쓴맛', values: [1, 1, 2, 3] },
]} />
<MiniAreaChart variant="comparison" entries={[
  { id: 'previous', taste: '감칠맛', values: [4, 6, 7, 10] },
  { id: 'current', taste: '감칠맛', values: [2, 3, 4, 6] },
]} />
```

웹·iOS 아카이브의 `미각 기록 겹침`과 `같은 미각 기록 비교`는 확인된 감각 존재 기록에서 식사 단위로 집계한다. 최근 8일 기록 상위 3개 미각의 최근 4일을 겹쳐 표시하고, 비교형은 1위 미각의 최근 4일과 직전 4일을 대응시킨다. 유효한 기록이 없는 날짜는 미확인 구간으로 남으며, 식사 기록 자체가 없는 날짜는 0이다. 강도·호감 점수를 빈도로 바꾸지 않는다. 원본 읽기·실패·계정 분리 규칙은 기존 패널을 공유한다.

## 중간 모서리 시각 보정 — 2026-10-10

기하학적 반경이 같아도 완만한 꺾임은 둥근 구간이 매우 짧아 뾰족하게 보인다. 중간 상단 모서리는 접점까지의 거리 `max(R / tan(각도 / 2), R)`를 사용한다. 양끝·하단은 기존 `R / tan(각도 / 2)`를 사용하고, 두 경우 모두 인접 변 길이의 절반을 넘지 않는다. R은 6이며 중간 모서리의 실제 곡률 반경은 각도에 따라 달라진다.

웹 단일·겹침·비교와 Remotion은 `src/components/system/plating/roundedAreaPath.ts`를 공유한다. iOS `TBMiniAreaChart.roundedPolygon`은 같은 계산을 사용한다. Figma의 기본/겹침/비교 3개 원본 벡터와 기존 인스턴스에도 반영했다. 색상·계열 순서·좌표 척도·데이터 집계·계정 및 상태 처리는 유지한다. 이번 제품 반영은 모서리 형태이며 Remotion의 순차 성장 애니메이션은 제품에 추가하지 않는다.

검증: `scripts/test-area-rounding.mjs`에서 SwiftUI와 웹의 cubic 경로를 비교한다. 실행 화면·운영 계정 검증과 구분한다. 상세 결과는 `output/area-corners-20261010/`에 기록한다.

2026-10-11 · 후속 수정: 비교형의 작은(진한) 면과 범례는 `mini-chart/main` 대신 기존 차트용 `taste/{axis}/chart/tint/20`에 연결한다. 웹은 `--tb-taste-{axis}-chart-tint-20`, iOS는 `miniChartTint20Color`를 사용한다. Light는 tint/20, Dark는 기존 chart/high(다크 main + 흰색 12%)이며 감칠맛은 각각 #C28EC3 / #BC83BD이다. 미니 막대 메인·일반 UI main·다른 영역·기하·집계는 유지한다.

2026-10-11 · 미각 겹침의 모든 계열과 범례도 차트용 tint/20으로 통일한다. 비교형에서 사용하는 같은 색상 함수를 재사용하며 모드별 값·기하·겹침 순서·집계는 유지한다.

## 값 1의 공통 높이 — 2026-10-11

웹 `miniAreaValueHeight`/`miniAreaPointRuns`와 iOS `TBMiniAreaGeometry.valueHeight`/`pointRuns`를 단일·겹침·비교 영역에서 함께 사용한다. Remotion의 단일·전환 영역도 웹 공통 함수를 재사용한다. 알려진 0은 바닥, null·음수·비정상 값은 연결을 끊는 미확인 구간으로 유지한다. 한 개의 알려진 표본은 같은 높이로 전체 너비를 채운다. 두 개 이상의 슬롯에서는 고립된 한 점으로 임의의 면을 만들지 않는다. 웹·iOS의 기존 단일 영역 하한 차이와 모든 값 1에서 최대 높이가 56px가 되던 불일치를 없앴다. 계정·기간·원본 집계·읽기/쓰기 및 상태 처리 경로는 유지한다.

2026-10-12 · Dark 원색을 Light와 공유하며 작은 비교 영역·미각 겹침과 범례는 `chart/tint/{step}`, 큰 비교 영역과 범례는 `chartTrack` 역할을 사용한다. 단계별 연결은 [컬러 가이드](color-style-guide.md)를 따른다.

다크 비교형 큰 영역은 캡슐 막대·라인의 넓은 배경 스트로크와 같은 tint/70으로 통일한다. 데이터의 면적 순서, 작은 영역 tint/20, 단일 영역 tint/60, 미각 겹침 3계열 tint/20은 그대로다.
