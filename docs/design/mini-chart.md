# 미니 그래프

기존 막대 예시 아래에 [미니 라인 그래프](mini-line-chart.md)를 추가했다. 미각 변화 카드의 기존 옅은 캡슐 트랙·2px 그라데이션 선·원형 노드를 독립 예시로 보여준다.

2026-10-07 · 홈 아카이브 카드 오른쪽에 사용하는 공통 그래프.

2026-10-09 · Figma의 `03 Components`에는 [대표 미니 그래프 한 개](https://www.figma.com/design/HHwQ9suI1czmYEwCQ6wW1W?node-id=1282-10498)만 둔다. 종류별 설명과 Light/Dark·기간·표시 변형은 `04 Patterns`의 [미니 그래프 전체 목록](https://www.figma.com/design/HHwQ9suI1czmYEwCQ6wW1W?node-id=1356-4629)에 모았다. 대표의 ‘전체 종류·변형’ 링크와 전체 목록의 돌아가기 링크로 이동한다. 전체 목록은 9개 종류, 19개 기존 원본의 Light/Dark 견본 38개이며 원본 그래프·값·제품 호출부는 변경하지 않았다.

| 항목 | 규칙 |
| --- | --- |
| 그래프 영역 | 132 × 56px/pt 고정 |
| 막대 배치 | 동일 너비의 열, 기본 열 간격 3, 막대 폭 최대 12. 주간 단일 계열은 간격 8 |
| 일주일 예시 | 1~7일, 막대 폭 12 · 간격 8. `12 × 7 + 8 × 6 = 132`, 양끝 추가 여백 없음 |
| 보름 예시 | 1~15일, 막대 폭 6, 간격 3 |
| 한달 예시 | 지정한 연·월의 1일~말일. 28~31개 날짜 칸을 전체 너비 132에 배치 |
| 그룹형 예시 | 4개 항목 × 2계열. 막대 폭 12, 쌍 내부 간격 2, 그룹 간격 8 |
| 값 0 | 막대 두께의 절반 높이. 기본 12 × 6, 촘촘한 형은 날짜 수에 따라 폭과 높이를 계산. 진한 끝점 없음 |
| 값 1 | 높이 = 막대 폭. 기본형 12 × 12, 촘촘한 형도 폭과 높이가 같은 원형 |
| 값 2 이상 | 값 1의 원형 높이부터 최댓값의 높이 56까지 선형 보간 |
| 결측 | 해당 위치를 비워 둠. 데이터 없는 배열에 가짜 막대를 만들지 않음 |
| 색상 | 불투명 chartTrack(Light tint/80 · Dark tint/70), 마지막 양수 값은 해당 모드의 미각 main 끝점 |
| 예제 흰 컨테이너 | 폭 164, 좌우 패딩 16. 제품 카드 자체의 규격과 별개 |

값 `v > 1`, 최댓값 `m`, 막대 폭 `w`일 때 높이는 `w + (v - 1) / (m - 1) × (56 - w)`다. 모든 값이 1이면 모두 원형이다. 유한한 음수·결측·비정상 값은 그리지 않으며 배열상의 위치는 보존한다. 0보다 크고 1보다 작은 값은 원형으로 표시하지만, 이 미니 그래프는 횟수 요약을 위한 표현이다. 정밀한 비율 비교에는 상세 차트를 사용한다. 막대가 매우 많으면 간격도 줄여 고정 영역 안에 유지한다.

일주일·보름·한달은 같은 월간 데이터를 기간별로 잘라 보여주는 예시이며 시계열·분포·빈 상태의 별도 변형을 제공하지 않는다. 상세 차트의 실제 비율 높이와 원본 집계 수치는 변경하지 않는다. 카드의 데이터 유무 판단·집계·기간 선택은 호출부 책임이다.

2026-10-11 · 주간 7칸의 가로 배치를 Figma·웹 `MiniChart`·iOS `TBMiniChart`에 맞췄다. 값 0과 결측도 원래 날짜 칸을 유지한다. 보름·월간·그룹형과 누적 막대는 기존 간격을 유지한다. 누적형이 공유하는 계산에는 `fitWeek: false`를 전달한다. 높이·색상·원본 기록·집계·기간과 계정 상태 처리는 변경하지 않는다.

그룹형은 `comparisonValues`에 이전 계열을 전달한다. 왼쪽은 이전(중립 회색 #666666), 오른쪽은 현재(미각색)이며 같은 인덱스가 같은 항목이어야 한다. 두 계열 전체의 공통 최댓값으로 높이를 계산해 같은 값은 같은 높이로 표시한다. 이전 계열은 Light 중립 회색 18% / Dark 불투명 뉴트럴 tint/70(#454545) 트랙, 현재 계열은 불투명 chartTrack(Light tint/80 · Dark tint/70)을 사용하며 마지막 양수 값에 해당 모드의 미각 main 끝점을 표시한다. 길이가 다른 배열의 없는 위치는 비워 두며 0으로 만들지 않는다. 항목이 많아지면 그룹 간격·쌍 내부 간격·막대 폭을 줄여 132×56를 유지한다.

```tsx
<MiniChart values={[1, 4, 3, 6]} comparisonValues={[0, 2, 4, 3]} axis="umami"
  label="이전 0, 2, 4, 3. 현재 1, 4, 3, 6." />
```

그룹형은 공용 React·SwiftUI 컴포넌트와 문서 예시에 추가했다. 실제 홈 카드는 기존 데이터를 유지하며 이전 기간의 집계·기간 라벨 연결은 별도다.

- [Figma 컴포넌트](https://www.figma.com/design/HHwQ9suI1czmYEwCQ6wW1W?node-id=1346-1917): `Content/Chart/Mini` 한 세트에서 `Period=주간`(197:1505), `Period=보름`(899:3688), `Period=월간`(787:3292)을 선택한다. 세 그래프의 기존 원본 ID와 132×56 기하는 유지했다. 모두 동일한 코드 컴포넌트에 대응하며 `MiniDense`·`MiniHalfMonth`를 독립 계열로 추가하지 않는다. 정보 없음 표본은 실제 0이나 특정 기간으로 취급하지 않는다. [예시와 적용 카드](https://www.figma.com/design/HHwQ9suI1czmYEwCQ6wW1W?node-id=752-3284)는 기존 연결을 유지한다.
- 그룹형 Figma 원본: `Content/Chart/MiniGrouped` 813:3630. 같은 `MiniChart` / `TBMiniChart`의 `comparisonValues` API에 대응한다.
- [플레이팅 예시](/design-system/components/mini-chart): 일주일·보름·한달 및 별도 그룹형 그래프, 기록한 식사·음식 전체 평가 카드를 유지한다.
- 웹: `src/components/system/plating/MiniChart.tsx`, `miniChartGeometry.ts`. 치수 원본은 `COMPONENT_TOKENS.miniChart`.
- iOS: `SystemParityComponents.swift`의 `TBMiniChart`·`TBMiniChartMetrics`. `HomeArchiveChartView`의 compact 막대와 `HomePeriodInsightCard`가 공유한다.
- 네이티브 표본: `--design-system-preview --plating-native-audit-capture --plating-mini-chart-capture`.

독립 그래프는 기간과 값의 의미를 접근성 요약으로 제공한다. 카드가 이미 같은 정보를 읽으면 그래프는 장식으로 숨긴다. 예제의 합성 값을 실제 제품 집계로 저장하지 않는다.

56px 높이 전체에 맞춘 R 6의 [미니 영역 차트](mini-area-chart.md)를 라인 그래프 바로 아래에 배치했다.

월간은 `month={{ year: 2026, month: 8 }}`처럼 달을 지정한다. `values[0]`이 1일이며 윤년을 포함해 28~31일의 위치를 유지한다. 전달되지 않은 날짜는 `null`로 남기고, 확인된 0만 0 높이 규칙을 적용한다. 당월의 미래 날짜도 호출부에서 null로 전달한다. 범위를 벗어난 값은 해당 달에 표시하지 않는다. 웹·Figma 예시는 2026년 8월의 합성 데이터이며 실제 제품 집계와 iOS API는 변경하지 않는다.

```tsx
<MiniChart month={{ year: 2026, month: 8 }} values={dailyCounts} axis="umami"
  label="2026년 8월 1일~31일 날짜별 기록" />
```

기간 예시는 같은 2026년 8월 합성 데이터를 사용한다. 일주일은 1~7일, 보름은 1~15일, 한달은 1~31일이다. 각 기간의 최댓값을 기준으로 높이를 정규화하므로 서로 다른 예시의 막대 높이를 절댓값으로 직접 비교하지 않는다. 월 후반을 보여줄 때는 16일~말일로 자르며 날짜 수는 달에 따라 달라진다.


## Figma 다크 그래프 밝기 검토 · 2026-10-10 · 2차

다크 그래프가 여전히 어둡다는 후속 의견을 반영해 밝기를 더 올렸다. 기존 그래프 원본 19종의 기하와 라이트 색상은 유지한다. 이 절은 Figma 검토 결과다. 아래 후속 작업에서 히트맵은 웹·iOS에도 동기화했으며 다른 그래프의 실제 색상 토큰 적용은 별도 작업이다.

| 역할 | Light | Dark |
| --- | --- | --- |
| 막대 트랙 | tint/80 | tint/20 |
| 기본 영역 | tint/60 | tint/10 |
| 여러 계열의 면·버블·트리맵·파이 | tint/40 | main |
| 같은 미각 비교의 큰 영역 / 작은 영역 | tint/80 / chart/tint/20 | tint/20 / chart/tint/20 |
| 히트맵 0 / 1 / 2 / 3 / 4개 이상 | tint/80 / 60 / 40 / 20 / main | tint/20 / tint/10 / main / high / highlight |
| 라인 트랙 / 선 시작 / 끝점 | tint/80 / tint/70 / main | tint/20 / main / highlight |
| 비교 막대의 중립 트랙 불투명도 | 18% | 50% |

`high`는 기존 다크 main과 흰색을 sRGB 채널에서 12% 혼합한 색, `highlight`는 25% 혼합한 그래프 전용 강조색이다. 일반 UI 팔레트 값은 바꾸지 않고 그래프 역할에서만 참조한다. 히트맵 다섯 단계의 밝기 순서는 유지한다. 달력 범위 밖 중립 셀과 빈 상태도 유지한다.

버블·트리맵 숫자와 아이콘은 `color/chart/on-bright-fill`을 사용하며 현재 여섯 채움색에서 대비 6.32–8.53:1을 확인했다.

검토 자료: `output/dark-mini-graph-color-20261010/verification-v2.json`. [다크 미니 그래프](https://www.figma.com/design/HHwQ9suI1czmYEwCQ6wW1W?node-id=1565-1439).

파이 그래프의 남은 영역은 `color/chart/remainder`를 사용한다. 라이트는 기존 neutral tint/80 `#E4E4E4`, 다크는 neutral main `#A3A3A3`이며, 남은 영역의 비율과 기하는 유지한다. 이 역할은 파이의 남은 영역에만 연결한다.

### 히트맵·전경 색상 후속 수정

히트맵의 월 바깥 회색 4칸은 `color/chart/heatmap-neutral`로 분리했다. 2026-10-10에는 Light #E4E4E4를 유지하고 Dark #2F2F2F를 #A3A3A3으로 밝혔다. 현재 색상은 아래 2026-10-12 조정을 따른다. 미래·미확인(null) 셀은 2026-10-12 후속 요청에 따라 웹·iOS 모두 테두리 없이 같은 뉴트럴 역할로 채운다. 확인된 0건은 미각색의 0단계 채움을 유지한다. 기존 Figma 합성 표본에는 null이 없어 그림은 유지하고 컴포넌트 정의를 이 규칙에 맞춘다.

꺼진 스위치 손잡이는 Dark #F5F5F5, 펼침 카드 선택 면과 분석의 뉴트럴 선택 면은 #484848, 일반 칩은 기존 neutral chip 역할 #343434로 연결했다. `tintSoft`는 Dark tint/70으로, 측정 루프는 tint/50부터 main까지 순서대로 밝아지는 10단계로 조정했다. 원시 tint 팔레트·일반 배경·그림자·딤·비활성 역할은 유지한다. 상태·집계·계정 데이터 경로를 변경하지 않는다.

색상 원본은 `src/constants/colorModes.ts`, CSS·Swift 생성기는 `scripts/build-color-modes.mjs`다. Figma 변경 목록과 검증 캡처는 `output/dark-foreground-20261010/`에 보관한다.

## 다크 미각 역할 동기화 · 2026-10-12

여섯 원색을 Light와 공유하고 표면 틴트와 그래프용 밝기 단계를 분리했다. 위 2026-10-10 Figma 검토 중 미각 트랙·면·선·끝점과 밝은 채움 위 글자 역할은 이제 웹·iOS에도 동일하게 연결한다. 그래프 5단계와 모드별 값은 [컬러 가이드](color-style-guide.md)를 따른다. 비교형 중립 트랙과 파이 남은 영역은 아래 후속 규칙을 따른다.

2026-10-12 후속 조정 · 캡슐 막대는 `chartTrack → Light tint/80 · Dark tint/70`을 사용하고, 원형 노드는 `taste/{axis}/main`을 사용한다. 감칠맛 Dark는 캡슐 #49364A / 원형 #B372B4다. 다크 캡슐을 tint/80에서 tint/70으로 한 단계 밝혔으며 원형 노드는 유지한다. Figma `mini-chart/main`도 미각 main에 직접 연결한다. 라인·영역·히트맵의 그래프 전용 단계는 유지한다.

다크 배경 톤 통일: 뉴트럴 비교 캡슐도 tint/70(#454545)을 사용한다. 비교 원형 노드의 기존 회색과 현재 원형의 미각 main은 유지한다. 라인 넓은 스트로크와 큰 비교 영역은 미각별 chartTrack(tint/70)에 맞춘다.

2026-10-12 최종 색상 통일: 라이트 라인 시작색은 웹·iOS·Figma 모두 일반 tint/70이다. 파이 남은 영역과 해당 범례는 color/chart/remainder(Light #E4E4E4 · Dark #A3A3A3)를 사용한다. 위 2026-10-10 검토표의 히트맵 단계는 현재 Light 80/60/40/20/main · Dark 70/50/30/10/main으로 갱신됐으며, 달력 밖 뉴트럴은 Light #E4E4E4 · Dark #454545다.
