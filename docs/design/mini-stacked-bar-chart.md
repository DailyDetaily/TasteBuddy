# 미니 누적 바 그래프

2026-10-07 · 한 기간의 구성비를 보여주는 도넛 다음으로, 여러 기간의 총량과 구성을 함께 비교하는 컴포넌트다.

132 × 56 고정 영역에 최대 폭 12의 막대를 간격 3으로 배치한다. 기간이 많아지면 기존 미니 바와 같은 가로 배치 규칙으로 폭과 간격을 줄인다. 각 계열과 범례는 불투명 `taste/{axis}/chart/tint/20` 토큰을 사용한다. Light는 tint/20(미각색 80%), Dark는 기존 chart/high(다크 main + 흰색 12%)를 따른다. 웹은 `--tb-taste-{axis}-chart-tint-20`과 Light 폴백, iOS는 `miniChartTint20Color`를 공유한다. 투명도·막대 기하·누적 계산·계정 데이터 경로는 변경하지 않는다.

각 레이어의 높이는 `해당 계열까지의 누적값 / 모든 기간 중 최대 총량 × 56`다. 모든 캡슐은 같은 하단 y=56에서 시작한다. 가장 긴 전체 합계 레이어를 뒤에 그리고 중간·가장 짧은 레이어를 그 위에 겹친다. 예를 들어 3·2·1이면 뒤부터 누적 높이 6·5·3이다. 각 레이어의 위·아래 끝을 모두 둥글게 하며, 높이는 늘리지 않는다. 위·아래에 같은 반경 `min(막대 폭, 높이) / 2`를 적용해 짧은 레이어도 대칭 캡슐 형태를 유지한다.

총량이 가장 큰 막대는 56을 채운다. 누적 높이는 값에 비례하며 각 범주의 값은 인접 누적 높이의 차이다. 0인 계열의 레이어는 그리지 않는다. 겹침과 둥근 캡으로 달라지는 노출 면적은 정확한 구성비가 아니므로 범례에 실제 값을 함께 제공한다.

모든 계열 값이 0인 기간에는 막대 폭의 절반 높이로 중립 위치 표시를 그린다. 한 계열이라도 결측·음수·비정상 값이면 그 기간 전체를 비운다. 배열 길이가 달라도 없는 값을 0으로 가정하지 않는다.

```tsx
<MiniStackedBarChart series={[
  { id: 'home', label: '집밥', axis: 'umami', values: [2, 3, 4] },
  { id: 'out', label: '외식', axis: 'sweet', values: [1, 2, 1] },
]} label="세 기간의 식사 기록: 집밥 2·3·4회, 외식 1·2·1회" />
```

서로 겹치지 않는 분류에 사용한다. 독립적인 미각 강도나 호감 점수를 합계로 쌓지 않는다. 계열 순서·기간·분류는 호출부가 결정하며 컴포넌트에서 집계하거나 저장하지 않는다.
