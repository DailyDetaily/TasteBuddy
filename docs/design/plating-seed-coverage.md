# SEED · Montage · 플레이팅 컴포넌트 대조

> 2026-10-01 구현 후속: 중복 역할을 묶은 **20개 계열**을 웹 카탈로그와 Figma에 추가했다. 현재 총 51개 계열이며, 아래 집계는 추가 전 감사 기록으로 보존한다. [추가 결과와 검토 순서](./plating-component-review.md). 기존 계열의 보완 과제를 모두 완료했다는 뜻은 아니다.

기준일: 2026-10-01 · [SEED 공식 Components](https://seed-design.io/components)와 61개 개별 문서를 읽었다. **현행 52개와 Deprecated 9개**를 분리했다. 같은 날 완료한 [Montage 대조](./plating-component-coverage.md)의 Figma·제품 근거에 연결했다.

**두 행은 단위가 달라 합산하지 않는다.** 예를 들어 SEED Text Input & Textarea는 1문서지만 Montage는 2원본이고, SEED Skeleton은 Montage의 3형태를 묶는다. 같은 누락이 여러 행에 나타나므로 누락 행 수가 새로 만들어야 할 컴포넌트 수와 같지 않다.

정리됨은 현재 플레이팅 v1의 해당 역할을 보유했다는 뜻이다. 두 참조 시스템의 모든 옵션 구현이나 제품 전체 검증을 뜻하지 않는다. 제외·보류에는 타사 고유 요소, 웹 문서 사이트 전용 역할, 현재 사용 근거가 부족한 항목이 포함된다.

## 이름만으로 합치면 안 되는 항목

- **Footer ≠ Action Area**: SEED Footer는 사이트 정보·정책 영역이다. 앱의 하단 CTA는 StepIndicator + PrimaryButton 조합 패턴으로 별도 관리한다. [SEED Footer](https://seed-design.io/components/footer)
- **Tag Group ≠ 선택 칩 그룹**: 정보 요약과 값 선택을 나눈다. TBWrapLayout/OverflowTagRow의 배치 규칙과 정보 의미도 구분한다. [SEED Tag Group](https://seed-design.io/components/tag-group)
- **Accordion ≠ 모든 Disclosure**: SEED는 여러 항목의 구조를 설명한다. Taste Buddy의 단일 펼침은 Collapsible 역할부터 등록한다. [SEED Accordion](https://seed-design.io/components/accordion)
- **Pagination ≠ StepIndicator**: 번호 기반 목록 이동과 온보딩 단계 표시는 다르다. 이전 Montage Dots의 단계 대응을 SEED Pagination에 확장하지 않는다. [SEED Pagination](https://seed-design.io/components/pagination)
- **Slider 코드 존재 ≠ 현재 제품 사용**: QuickTasteCalibrationScreen에 range가 있지만 외부 연결을 찾지 못했다. 현재 필수 누락으로 올리지 않았다. [검색 근거](../../output/plating/seed-coverage/source-search-20261001.json)
