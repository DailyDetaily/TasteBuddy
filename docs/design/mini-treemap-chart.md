# 미니 트리맵

2026-10-09 · 132 × 56. 둥근 사각형과 캡슐을 빈틈 없이 가깝게 배치하는 라운드 트리맵 견본이다. 버블 차트 아래에 별도 컴포넌트로 둔다. 버블은 2–3개 항목, 트리맵은 여러 항목의 면적 비교에 사용한다.

## 디자인 견본의 데이터 계약

- 단위: 분류별 합성 요리 기록 수. 값은 기존 6개 예시의 3·8·18·12·6·4다.
- 분류 색상(2026-10-12): 한식 3은 `bitter`(초록), 중식 18은 `umami`(보라). 같은 분류를 쓰는 버블 3개 견본·요약 카드·범례·Remotion·Figma가 이 매핑을 공유한다. 맛 측정값이 아닌 항목 식별색이다.
- 기간·날짜·시간대: 기간이나 날짜가 없는 디자인용 견본이다. 저장일을 식사일로 해석하지 않는다.
- 분모: 유효한 양수의 합계 51. 색이 채워진 면적이 이 구성비에 비례한다.
- 중복: 각 항목 ID는 고유하다. 집계나 원본 기록의 중복 제거는 이 표시 컴포넌트에서 수행하지 않는다.
- 0·미확인·미래: 0은 면적이 없다. null·음수·비정상 값은 그리지 않고 미확인으로 설명한다. 날짜 입력이 없어 미래 날짜 판정은 적용하지 않는다.
- 계정: 계정과 무관한 합성 견본이다. 이번 추가는 제품의 기존 계정별 버블·음식 아이콘 차트나 집계 경로를 변경하지 않는다. 제품 적용은 [데이터 컴포넌트 계약](data-component-contract.md)을 따른다.

## 표현

큰 값부터 공간을 이분할한 기존 배치를 좌우·상하 반전해 가장 큰 블록은 오른쪽, 가장 작은 블록은 왼쪽 위에 오도록 배치한다. 블록의 면적·크기·간격은 유지한다. 셀의 위치와 거리는 별도의 수치 축이나 시계열을 의미하지 않는다. 모서리 반경은 짧은 변의 절반으로 설정해 원·캡슐 형태를 만든다. 기본 간격은 1px다.

모서리에서 빠지는 면적까지 포함해 배치 비중을 보정하므로 실제 색칠된 면적이 값에 비례한다. 수치·색상·단위는 원본 입력을 그대로 사용하며 표시용 면적 보정을 저장하지 않는다. 색은 기존 taste/{axis}/tint/40, 숫자는 text/primary 토큰이다. 숫자는 기본 10px Medium이며 작은 셀에서 축소한다.

이 컴포넌트는 현재 플레이팅과 Figma의 합성 예시에만 연결한다. 제품의 로딩·실패·계정 전환 등을 이 견본으로 검증했다고 주장하지 않는다.
