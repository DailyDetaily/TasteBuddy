# 플레이팅 컴포넌트 커버리지 감사

> 2026-10-01 구현 후속: 중복 역할을 묶은 **20개 계열**을 웹 카탈로그와 Figma에 추가했다. 현재 총 51개 계열이며, 아래 집계는 추가 전 감사 기록으로 보존한다. [추가 결과와 검토 순서](./plating-component-review.md). 기존 계열의 보완 과제를 모두 완료했다는 뜻은 아니다.

기준일: 2026-10-01 · 현재 `/Users/sinjunho/Desktop/Taste Buddy` 체크아웃.

추가 대조: [SEED · Montage · 플레이팅](./plating-seed-coverage.md). SEED 현행 52문서는 정리됨 7, 보완 필요 16, 누락 15, 제외·보류 14로 분류했다. 아래 Montage 44원본과 집계 단위가 다르므로 합산하지 않는다. 알림 배지·입력형 선택 버튼·휠 선택기·스크롤 페이드는 추가로 확인한 누락이다.

**아직 모든 컴포넌트가 정리된 상태는 아니다.** Montage의 공개 컴포넌트 원본 44개를 현재 플레이팅 31계열 및 실제 iOS/Web 소스에 대조했다. **보완 필요 21개**, **정리됨 8개**, **누락 11개**, **현재 제품에 불필요 4개**다. 이번 작업은 조사와 매트릭스 작성이며 누락 항목의 구현 완료를 뜻하지 않는다.

## 범위와 판정

- **정리됨**: 현재 v1의 해당 역할이 카탈로그·Figma에 대응한다. Montage의 모든 옵션 복제나 제품 전체 동작 검증을 뜻하지 않는다.
- **보완 필요**: 대응 항목은 있으나 실제 제품의 역할·상태·속성·플랫폼 계약이 일부 빠져 있다.
- **누락**: 실제 소스에 사용 근거가 있으나 새 플레이팅 항목/패턴이 없다.
- **현재 제품에 불필요**: 타사 고유 브랜드는 이식 제외. 그 외는 명시된 검색 범위에서 사용 근거를 찾지 못해 보류한 것이며 영구 불필요 판정이 아니다.
- P1: 실제 입력·상세 탐색·오류 복구를 설명하는 데 필요한 누락. P2: 표현·슬롯·미디어·편집 속성 확장.

Montage 25페이지를 읽어 **350 component sets + 41 standalone components = 391개 원본**, 세트 내부 **1,269개 variant**를 확보했다. 내부 부품과 아이콘을 별도 제품 컴포넌트로 부풀리지 않았다.

## 구현 순서와 완료 조건

1. **기간·상세 모드 선택기**: TasteDetailPeriodPicker/SectionPicker를 카탈로그·Figma에 등록. 실제 기간 5종, 모드 문구, 현재 선택, 큰 글자 메뉴 전환, 웹 키보드 조작을 일치시킨다.
2. **상세 근거 구성**: Scope·ValueRow·Disclosure와 ChartPanel/Group/BarPlot을 연결. 출처/기간/단위·미확인과 0·접힘/펼침·큰 글자 배치를 예제로 확인한다.
3. **상태와 배치**: FlowLoading/Retry, WrapLayout/OverflowTagRow. 재시도 callback, 로딩 전환, 긴 태그·좁은 폭·+N 계산의 계약을 확인한다.
4. **입력과 행동**: Textarea·Select·ActionArea·TextButton·ToggleIcon. OS 컨트롤은 사용 패턴으로 다루고 취소/오류/disabled/초점을 확인한다.
5. **기존 계열 확장**: 실제 버튼 tint·Chip 변형·카드 슬롯·아바타 크기·Skeleton·Thumbnail·아이콘 목록을 정리한다.

각 작업은 소스 근거 → 문서/데모 → 편집 가능한 Figma → 상태·속성 검사까지 연결해야 완료로 판정한다. 이번 감사만으로 위 상태를 정리됨으로 올리지 않는다.
