# 인사이트 분류 아이콘

2026-10-12. 홈 인사이트, 요약 카드, 발견 카드의 헤더는 같은 5개 분류 아이콘을 사용한다.

## 분류 정의

| 분류 | 카드가 답하는 질문 | 포함 예시 | 현재 공통 도안 |
| --- | --- | --- | --- |
| 경험 | 무엇을 얼마나 경험하고 기록했나? | 식사·메뉴·식당·음식 종류, 출처 구성, 처음·반복 경험, 날짜별 기록 빈도 | Lucide 기본 Globe — 바깥 원, 세로 원호, 가운데 가로선 |
| 감각 | 어떤 감각을 어느 정도로 느꼈나? | 맛·향·식감의 존재와 강도, 함께 기록한 감각 | Speech |
| 취향 | 무엇을 좋아하고 알맞다고 느꼈나? | 음식 전체 평가, 감각별 호감, 강도의 알맞음 | Lucide Heart — 채움 없는 2.2px 라인 |
| 맥락 | 어떤 조건에서 반응이 달라지나? | 음식 종류·부위·먹는 시점·강도와 반응의 연결 | Orbit — 중심 경험을 둘러싼 조건 |
| 변화 | 같은 범위의 이전·최근 기록이 어떻게 달라졌나? | 경험 수, 감각, 호감·알맞음의 기간 비교 | RefreshCw |

대표 분류는 데이터 원본이나 그래프 형태가 아니라 카드의 핵심 질문으로 정한다. 기간이 적힌 기록 수는 경험, 이전 기간 대비 증감이 주제이면 변화다. 음식 출처별 기록 구성은 경험이며 조건별 반응을 비교할 때 맥락이다. 분류를 색이나 카드 제목 문자열에서 추론하지 않는다.

## 표시 계약

- 웹 `InsightCategoryIcon`, iOS `TDCategoryIcon`이 동일한 분류-도안 매핑을 담당한다. 헤더는 16, 홈 인사이트는 24를 사용한다. 음식 종류 아이콘과 같은 Lucide 기준으로 24×24 원본, 중앙 2px 획(`medium`), round cap/join, fill none, 최소 1px 잉크 여백과 분리 요소 간 2px 목표 간격을 사용한다. 16·20·24px는 비례 축소한다. 취향도 채움 없이 표시한다. 취향 원본 도안은 2px이며 제품의 모든 분류 사용처에서는 2.2px(`strong`)로 표시한다.
- 원본 도안은 2px로 제작한다. 홈 미니 카드의 2.2px(`strong`)는 사용처의 별도 표시값으로 유지하며 원본 SVG에 섞지 않는다. Figma의 `Icon/Insight/preference`는 제품 표시값 2.2px를 사용하고, 2px 원본은 `current/preference.svg`로 별도 보존한다.
- 그래프가 있는 요약 카드 헤더 아이콘 색은 메인 그래프 미각의 main 토큰을 따른다. 그래프가 없는 분류 아이콘은 해당 분류색을 사용한다. 그래프·범례는 자신의 데이터 계열색을 유지한다. 개별 음식 아이콘은 그래프 안의 항목 구분에 사용한다.
- 웹 `PeriodCard`와 일반 `InsightSummaryCard`는 분류를 명시한다. 미각 변화 전용 카드는 기본 변화이며 조건 비교의 호출부는 맥락을 명시한다.
- iOS `HomePeriodInsightCardData.category`는 표시용 메타데이터다. `tasteClue`를 재사용하는 감각·취향·맥락 카드는 어댑터에서 실제 분류를 전달한다. 홈 음식 전체 평가는 취향, 기록 수와 메뉴·식당은 경험이다.
- 범용 버튼, 공유·삭제 등 기능 아이콘과 그래프의 상승·하강 지표는 이 분류 아이콘에 포함하지 않는다.

## 확정 도안과 출처

맥락은 Lucide Orbit, 변화는 Lucide RefreshCw로 확정했다. 웹·iOS·Figma에서 같은 분류 매핑을 사용한다. RefreshCw는 ‘변화’ 라벨과 함께 쓰는 분류 아이콘이며 새로고침 액션을 추가하지 않는다. 경험은 2026-10-14 요청에 따라 Lucide 0.487.0 기본 Globe를 사용한다. 바깥 원 r=10, 세로 원호 r=14.5, 가운데 가로선 y=12이며 감각은 Speech를 사용한다.

취향은 기본 Lucide Heart를 사용한다. 심볼 꽃잎 기반 파생안 대신 사용자가 최종 선택한 기본 하트 경로를 사용하며, 원본 도안은 2px, 제품의 분류 아이콘은 채움 없는 2.2px 라인이다.

`output/insight-icons-20261012/current/`와 `proposal/`는 2026-10-12 당시 도안이다. 경험의 최신 기본 Globe 원본은 `output/experience-globe-20261014/globe.svg`에 있다. 각 원본의 `activeHeader`에는 취향의 2.2px 표시값이 반영된다. Orbit·RefreshCw·Speech·Heart는 설치된 Lucide 0.487.0을 따른다. 이전 조건 연결·기간 비교 시안은 각각 `context-round-candidates/previous-condition-links.svg`, `change-refresh-candidate/previous-period-comparison.svg`로 보존한다. 꽃잎 하트 실험은 `petal-heart/`에 남아 있으나 최종 적용 도안은 아니다.

## 데이터 계약과 검증 범위

이번 변경은 분류의 표시 연결에 한정한다. 기존 계정 원본 → 검증 집계 → 요약 카드 경로를 재사용하며 API·테이블·원본 레코드·집계값을 추가하지 않는다. 카드별 식사/요리/응답 단위, 기간, 확정 식사일과 현지 시간대, 분모, 중복 제거, 날짜 미확인/미래 제외 및 계정 범위는 [데이터 컴포넌트 계약](data-component-contract.md)을 그대로 따른다.

로딩·확인된 빈 상태·오류/재시도·오프라인·계정 전환 처리와 상세 이동을 보존한다. 분류를 표시한다고 원본 응답 척도가 바뀌지 않으며 별점을 기존 호감 범주로 변환하지 않는다. 디자인 표본은 합성임을 표시한다. 소스·빌드·로컬 렌더 검증은 운영 계정의 서버 왕복 검증을 뜻하지 않는다.
