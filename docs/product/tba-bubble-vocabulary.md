# TBA 미각 버블 어휘 전체 목록

모든 표현은 검토 후보다. 중앙 → 구체화 → 세밀한 특징 순으로 읽는다. 가까운 표현은 자동 동의어나 호감 점수가 아니다.

## 공통 미각

| 중앙 | 구체화 | 세밀한 특징 |
| --- | --- | --- |
| 달콤한 | 은은한 단맛 | 끝에 살짝 단맛 · 씹을수록 단맛 |
| 새콤한 | 또렷한 산미 | 첫입에 오는 산미 · 삼킨 뒤 남는 산미 |
| 짭짤한 | 또렷한 짠맛 | 첫입의 짠맛 · 끝에 남는 짠맛 |
| 쌉싸름한 | 또렷한 쓴맛 | 혀에 남는 쓴맛 · 삼킨 뒤 쓴맛 |
| 감칠맛 | 진한 감칠맛 | 씹을수록 감칠맛 · 길게 남는 감칠맛 |
| 기름진 | 느껴지는 기름기 | 표면의 기름기 · 입술에 남는 기름기 |

## 바삭함의 차이

| 중앙 | 구체화 | 세밀한 특징 |
| --- | --- | --- |
| 바삭한 | 얇고 바삭한 | 얇게 파삭 부서지는 · 입안에서 잘게 부서지는 |
| 바삭한 | 단단하게 바삭한 | 첫입에 단단한 · 깨물 때 큰 소리가 나는 |
| 바삭한 | 겉면이 바삭한 | 가장자리만 바삭한 · 표면 전체가 바삭한 |
| 푸석한 | 가루처럼 부서지는 | 씹으면 가루가 되는 · 가루가 입안에 남는 |
| 바삭한 | 바삭함이 오래가는 | 식어도 바삭한 · 소스에 닿아도 바삭한 |
| 부드러운 | 눅눅해진 겉면 | 소스에 젖어 부드러운 · 식으며 눅눅해진 |
