# 미각 버블·디테일 태그 중심의 TBA 수집

작성일: 2026-09-06 · 상태: 구현·통합 검사 및 시뮬레이터 화면 확인 완료

TBA의 주 입력은 사용자가 직접 고른 미각 버블과 디테일 태그다. 선택한 감각에 평가·강도·알맞음·대상·시점을 덧붙여 해석에 필요한 자료를 수집한다. 메모는 선택으로 담기 어려운 내용을 보충하는 선택 입력이다. 문장 작성이나 문장 해석 성공이 기록 완료의 조건이 되지 않는다.

## 기존 화면에서 수집하는 순서

1. 메뉴 선택 뒤 별도 화면에서 디시 전체 호감도를 고른다. `정말 좋았어요`, `좋았어요`, `보통이었어요`, `아쉬웠어요`, `많이 아쉬웠어요`의 5단계다.
2. 기존 미각 지도에서 기억에 남는 버블을 고른다. 하나부터 다음 단계로 진행할 수 있으며 최대 세 개라는 기존 상한을 유지한다.
3. 선택한 버블의 디테일 태그를 고른다. 태그가 어떤 버블을 구체화하는지 연결을 보존한다.
4. 필요한 감각에만 평가나 조건을 선택한다. 모든 감각을 평가하거나 모든 조건을 채울 필요는 없다.
5. 메모 없이도 저장한다. 저장된 선택과 직접 평가로 인사이트를 다시 계산한다.

지도·버블·디테일 태그의 기존 구조와 구성 요소를 재사용한다. 이번 범위는 현재 화면의 버블 72개와 디테일 태그 60개다. 별도 설계한 845개 어휘 전체와 음식별 지도 확장은 이번 변경에 자동으로 포함하지 않는다.

## 선택이 뜻하는 데이터

| 입력 | 수집하는 의미 | 비워둔 경우 |
| --- | --- | --- |
| 디시 전체 5단계 호감도 | 이 음식 전체에 대한 평가. 다섯 원값을 별도 척도로 보존한다. | 과거 미응답을 평점이나 감각 평가로 채우지 않는다. |
| 미각 버블·디테일 태그 | 해당 표현을 이번 음식에서 직접 선택했다는 보고 | 미선택이며 감각의 부재나 싫어함을 뜻하지 않는다. |
| 좋았어요·보통·아쉬웠어요 | 해당 선택에 대한 직접 평가 | 호감 미응답이다. 감각 선택·강도·전체 평점으로 채우지 않는다. |
| 감각의 강도 | 해당 선택을 얼마나 강하게 느꼈는지 | 강도 미응답이다. 지도 배치용 숫자로 채우지 않는다. |
| 약해서 아쉬움·알맞음·강해서 부담 | 그 감각의 수준이 원하는 정도와 맞았는지 | 알맞음 미응답이다. 강도나 호감과 별도로 유지한다. |
| 대상 | 전체 음식·소스·국물·겉·속 등 선택이 적용되는 범위 | 특정 부위로 확정하지 않는다. |
| 시점 | 첫인상·중간·마무리 등 감각을 보고한 시점 | 특정 시점으로 확정하지 않는다. |
| 버블과 태그의 연결 | 사용자가 어떤 감각을 구체화하려고 태그를 골랐는지 | 다른 버블의 평가·대상을 자동으로 가져오지 않는다. |
| 추가 메모 | 사용자가 직접 덧붙인 내용 | 빈 메모를 그대로 저장한다. 선택 요약 문장을 새 원문으로 생성하지 않는다. |

예를 들어 `구운 향`을 고른 사실은 향의 보고다. 여기에 `좋았어요`를 선택하면 해당 향의 직접 호감이 된다. 함께 고른 `바삭함`은 별도의 감각이며, 향에 대한 호감을 바삭함에도 적용하지 않는다. `강하게`와 `알맞음`은 동시에 선택할 수 있다. 강한 감각이 그 사용자에게 알맞았다는 구체적인 조건을 보존한다.

## 전체 평가와 감각 평가의 관계

`전체적으로 좋았어요 + 산미가 조금 아쉬움`과 `전체적으로 많이 아쉬웠어요 + 산미가 조금 아쉬움`에서 산미에 대한 표현은 동일하게 보존한다. 두 번째 기록의 전체 만족도가 낮다는 이유로 산미 불호를 더 강한 값으로 바꾸지 않는다. 전체 불만족은 식감·온도 등 다른 이유에서도 생길 수 있다.

전체 평가는 같은 기록의 감각 평가를 이해하는 맥락이다. 여러 기록에서 어떤 감각의 아쉬움과 전체 만족도가 함께 변하는지 살피는 후속 분석에 쓸 수 있지만, 이번 구현은 감각별 기여도나 원인을 계산하지 않는다. 전체 5단계 평가 하나에서 개별 감각 호감이나 메인·윙을 생성하지 않는다.

디시 종류는 버블 후보를 먼저 탐색할 위치에 반영한다. 전체 평가는 실제 문구에 평가 의미가 명시된 디테일 태그의 추천에만 제한적으로 반영한다. 강함·발효향·긴 여운을 자동으로 아쉬운 감각으로 분류하지 않는다. 추천 목록은 답변이 아니며, 반대 감각과 전체 목록, 이미 고른 선택을 유지한다. 기존 중립 버블을 호감도별 다섯 문구로 복제하지 않는다.

## 저장과 정제

`DiningEntry.sensorySelections`에 선택 종류, 고정 ID, 카탈로그 버전, 당시 표시 라벨, 선택별 평가·조건·연결을 저장한다. 초기 계약 버전은 `dining-sensory-selection/1`이다.

`DiningEntry.overallEvaluation`은 별도 선택 객체다. 질문과 응답의 원래 라벨·버전·응답값을 보존하고, `whole_dish` 범위를 갖는다. 식후에 입력했다는 이유로 감각 시점을 `after_meal`로 채우지 않는다. 기존 개별 감각 3단계 평가와 과거 `rating`은 이 5단계와 서로 다른 자료다.

- 고정 선택은 ID와 버전의 의미 계약으로 정제한다. 선택 라벨을 자유 문장처럼 다시 읽어 의미를 추측하지 않는다.
- 화면의 축과 지도 배치용 강도 숫자는 분석 근거가 아니다. `bitter-roasted`의 `구운 향`은 향이며, `fat-soft-texture`의 `부드러운 질감`은 질감이다.
- 의미가 넓은 표현은 그 표현의 범위를 유지한다. `중심이 또렷함`을 특정 감각의 강도나 호감으로 확대하지 않는다.
- 선택 문구가 명시한 강도·대상과 추가 응답이 충돌하면 해당 부분을 유보한다. 원래 선택과 응답을 모두 보존한다.
- 미지의 ID·버전·직접 만든 태그는 원래 값을 보존한다. 현재 계약으로 확인할 수 없는 의미를 임의로 채우지 않는다.
- 추천 목록에 나타난 것과 직접 선택한 것을 구분한다. 추천 노출만으로 관찰이나 호감을 생성하지 않는다.
- 동일 기록의 버블·태그·평가를 독립된 식사 여러 번으로 세지 않는다. 선택 변경·해제와 기록 삭제는 이후 분석에 반영한다.

`sensorySelections == nil`인 과거 기록만 기존 ID 목록의 호환 경로로 읽는다. 과거 기록에서 존재하지 않았던 직접 평가를 만들지 않는다. `sensorySelections == []`는 명시적으로 비운 선택이므로 과거 ID 목록을 다시 불러와 되살리지 않는다.

기존 자동 생성 메모와 직접 작성한 메모를 구분한다. 과거 자동 요약과 일치하는 문장은 선택 이외의 새로운 관찰로 사용하지 않으며, 저장된 원문 자체는 보존한다.

새 피드백과 메뉴 입력 초안에 자동 메모·임의 평점을 채우지 않는다. 과거 평점 값은 보존하되 새 감각 호감의 근거로 사용하지 않는다. 새 초안은 미완료 상태로 시작한다.

## 해석과 근거 표시

선택한 감각과 직접 평가를 기존 개인 인사이트·메인·윙 분석으로 전달한다. 평가를 비워도 감각 정보는 보존하지만 좋아하거나 싫어한다고 판단하지 않는다. 단어의 뜻을 더 좁힐 근거가 없으면 그 표현 자체에 대한 평가와 일반 감각 선호를 구분한다.

근거 화면은 선택한 버블·태그, 실제로 누른 평가·조건, 추가 메모를 구분한다. 선택을 설명하기 위해 만든 문장을 사용자가 직접 쓴 인용문으로 표시하지 않는다. 모든 출력은 저장된 원래 선택으로 돌아갈 수 있어야 한다.

## 검증 범위

선택 계약의 누락, 감각 영역 오인, 없는 호감 생성, 다른 선택으로 평가 전파, 강도와 호감 혼동, 미응답과 중립 혼동, 복원·수정·해제 오류를 검사한다. 빈 메모 상태에서 직접 선택만으로 개인 해석이 생성되는지도 확인한다.

- 전체 5단계 평가를 포함한 Node 관련 검사 110개가 통과했다. 선택 라벨의 정확한 출처 검증, 선택 identity 보존, 실제 로컬 저장소의 재정렬·정정·해제와 시점별 조회를 포함한다.
- 데이터 계약 생성 검사 두 개가 통과했다. 기존 정제 예문 135개·메인/윙 15개와 별도로 선택 132개·선택 비교 예문 277개·전체 평가 예문 9개를 포함한다. 생성 예문은 양쪽 구현의 일치 검사이며 독립적인 의미 정답과 구분한다.
- 전체 5단계 평가를 포함한 iOS 앱·테스트 빌드와 XCTest 230개가 모두 통과했다. 마지막 안내 문구 변경 후 관련 흐름 검사 6개를 한정 재실행하여 통과했다. 최종 문구 변경 후 전체 230개를 다시 실행한 것은 아니다.
- 전용 iPhone 17 Pro 시뮬레이터의 가상 기록으로 전체 평가·미각 지도·디테일 입력·분석 화면을 실행하고 캡처를 확인했다. 마지막 안내 문구도 재빌드 후 디테일 화면에서 다시 확인했다. 실제 기기와 전체 터치 동작, VoiceOver 조작은 검증하지 않았다.
- 실제 외부 LLM/API 호출은 0회이며, 운영 API 연결은 보류했다.

현재 입력 화면은 완료 저장에 미각 버블 하나 이상을 요구한다. 데이터 계층의 `[]` 해제·재시작 검사는 전체 선택 해제를 화면에서 저장할 수 있다는 뜻이 아니다. 모든 버블을 지운 상태의 완료 저장은 현재 UI에서 제공하지 않는다.

기존 자유 문장 개발 세트의 `39/50 미해석 포함`은 자유 문장 경로의 검증 이력이다. 선택형 입력의 성능 수치로 사용하지 않는다. 선택 ID 매핑과 프로그램 검사가 통과해도, 사용자가 라벨을 같은 뜻으로 이해하는지와 실제 인사이트가 유용한지는 별도 검증이 필요하다.

온보딩 재설계에서도 짧은 선택 입력을 우선한다. 일반적으로 선언한 취향과 실제 식사에서 고른 감각은 서로 다른 근거 종류로 유지한다. API 연결은 보류하며 이번 선택형 수집에 실제 LLM 호출을 요구하지 않는다.
