# Docs Index

This folder is organized by purpose so content work, design work, and operations notes do not compete in one flat list.

## Structure

- `content/intake/`
  - Restaurant intake CSVs used for MVP content generation
  - Includes the intake template
- `content/planning/`
  - Content planning notes, shortlist decisions, and worklists
- `design/`
  - Design and screen-specific replan notes
- `operations/`
  - Catchtable workflow docs, batch run logs, and Supabase setup notes
