# 🎯 온보딩 디지털 영점 조절 (Digital Anchoring)

## 📌 핵심 개념 (Core Concept)
하드웨어(물리적 미각 측정 키트)가 없는 소프트웨어 MVP 단계에서, 유저의 초기 미각 데이터를 가장 빠르고 정확하게 수집하기 위한 전략. 추상적인 점수(1~10점)를 묻는 대신, **대한민국 국민 누구나 아는 대중적 F&B 가공식품의 맛을 영점(0, Zero-Point)으로 설정**하여 유저의 상대적인 미각 위치를 파악한다. 이를 통해 [[콜드 스타트(Cold Start)]] 문제를 마찰 없이 해결한다.

## 📐 6축 미각 앵커링 기준표
*각 축의 0점은 기준 음식의 기본 레시피이며, 슬라이더를 통해 -3부터 +3까지 상대 평가를 진행한다.*

* **🧂 짠맛 (Salty)**
  * **기준점:** 신라면 (기본 레시피 국물)
  * **스펙트럼:** `[-3] 짜다 <---> [0] 딱 맞다 <---> [+3] 싱겁다
* **☕️ 쓴맛 (Bitter)**
  * **기준점:** 스타벅스 아메리카노 (톨 사이즈 기본 투샷)
  * **스펙트럼:** `[-3] 너무 쓰다 (연하게) <---> [0] 기분 좋다 <---> [+3] 연하다 (샷 추가 필요)`
* **🍌 단맛 (Sweet)**
  * **기준점:** 빙그레 바나나맛우유
  * **스펙트럼:** `[-3] 너무 달다 (텁텁함) <---> [0] 기분 좋게 달다 <---> [+3] 아쉽다 (더 단것 선호)`
* **🍋 신맛 (Sour)**
  * **기준점:** 수제 햄버거집의 기본 피클 (또는 레몬에이드)
  * **스펙트럼:** `[-3] 불호 (인상 찌푸려짐) <---> [0] 적당히 즐긴다 <---> [+3] 극호 (강한 산미 찾아먹음)`
* **🥓 지방 (Fat)**
  * **기준점:** 삼겹살 구이 (첫 입의 고소함)
  * **스펙트럼:** `[-3] 느끼하다 (목살 선호) <---> [0] 고소하다 <---> [+3] 부족하다 (대창/마블링 선호)`
* **🍲 감칠맛 (Umami)**
  * **기준점:** 평양냉면 육수 (또는 맑은 고기 국물)
  * **스펙트럼:** `[-3] 맹맛이다 (조미료 필요) <---> [0] 은은하게 느껴짐 <---> [+3] 깊게 반응함 (매우 예민)`

## 🎨 UI/UX 설계 지침 (Clinical Softness)
설문이 병원 문진표처럼 보이지 않고, 세련된 심리테스트처럼 느껴져야 한다. 철저히 [[DESIGN_SYSTEM.md]] 규격을 따른다.

1. **One Question Per Page:** 인지적 부하를 줄이기 위해 한 화면에 하나의 질문만 노출.
2. **컨테이너:** `--tb-color-bg-page` 배경 위에 `SectionCard` 컴포넌트로 질문과 슬라이더를 감싼다.
3. **인터랙션 (Slider):** * 핸들러 이동 시 `180ms` Easing 적용하여 부드럽고 쫀득한 조작감 제공.
   * 채워지는 트랙 색상은 해당 미각의 **Taste Palette 메인 컬러**(`--tb-taste-...`)로 동적 변경.
4. **결과 도출:** 6개 질문 완료 시, 내부적으로 0~100 스케일의 절대 좌표로 변환하여 유저의 첫 번째 `[[Taste DNA 레이더 차트]]`를 화려한 트랜지션과 함께 렌더링.

* [[행동 기반 역치 측정]] (예: 냉면에 식초 몇 바퀴 두르나요?)
