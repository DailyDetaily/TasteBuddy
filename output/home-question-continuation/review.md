# 홈의 남은 질문 연속 표시

2026-09-14. 홈 질문이 메뉴별 대표 최대 3개 ID로 고정되어, 그 질문을 완료하면 다른 미응답 질문이 있어도 완료 안내만 남던 문제를 수정했다.

## 변경

- 홈은 현재 저장 가능한 미응답 질문 배열을 그대로 렌더링한다. 메뉴별 대표 1개, 최대 3개, 고정 ID 배치를 거치지 않는다.
- 남은 질문 카드를 모두 각각 표시한다. 겹친 카드와 대기열 펼치기 버튼을 사용하지 않는다.
- 하나를 답하면 해결된 카드만 사라지고 나머지 카드가 같은 영역에 계속 남는다.
- 마지막 질문이 끝나면 ‘이번에 보여드린 질문에 답변을 기록했어요’와 ‘지금 확인할 질문이 없어요’를 표시하지 않는다. 질문 컨테이너 자체를 렌더링하지 않는다.
- 홈에 모든 질문이 있으므로 질문 영역의 ‘질문 전체보기’ 버튼도 표시하지 않는다. 전체 질문 시트 구현은 별도의 QA 진입과 기존 코드에 보존했다.

## 검증

- `unit-1`: 질문 통합 26개와 질문 저장·해결 18개, 총 **44개 통과**, 실패 0개, 7.294초, xcodebuild 종료 코드 0.
- 답변 전 3개를 넘는 질문이 모두 유지되고, 첫 질문 저장 후 해결된 ID만 빠지며 나머지 ID 집합이 그대로 남는지 확인했다.
- `ui-build-1`: UI 테스트 빌드 통과.
- `ui-1`: **2개 통과**, 실패 0개, 28.680초. 3개를 넘는 카드를 홈에 함께 표시하는 경우와 두 질문을 연속 저장한 뒤 질문 영역·완료 문구·빈 상태 문구가 모두 사라지는 경우를 실제 SwiftUI 앱에서 확인했다.
- 최초 UI 실행은 단위 테스트 종료 뒤 전용 시뮬레이터가 Shutdown 상태여서 러너 설치 전에 종료됐다. 같은 전용 QA 시뮬레이터를 다시 부팅한 뒤 최종 실행이 통과했다.
- `git diff --check` 통과.

검증 환경은 iOS 26.5, 402×874pt 전용 QA 시뮬레이터와 합성 기록이다. 실기기와 운영 사용자 기록은 이번 검증 범위가 아니다.
