# Design System

Create a practical design foundation that can be used directly in code.

## Workflow
- Identify recurring visual patterns before defining tokens or primitives.
- Organize decisions into colors, typography, spacing, and shared component rules.
- Favor a small, coherent token set over an exhaustive but noisy one.
- Express reusable values as CSS variables or equivalent project conventions.
- Document how the system should be applied so future UI work stays consistent.

## Output
- Provide the design token structure.
- Provide CSS variables or equivalent implementation.
- Provide brief documentation for usage and intent.
