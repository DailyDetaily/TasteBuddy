# UI Improvement

Refine the interface so the important content is easier to notice and use.

## Workflow
- Diagnose the biggest clarity issues first: spacing, hierarchy, grouping, or readability.
- Preserve the product's intent and content while improving presentation.
- Strengthen visual rhythm with consistent spacing and clearer alignment.
- Improve headings, labels, and contrast cues when the screen is hard to scan.
- Keep changes intentional and avoid decorative noise.

## Output
- Provide the improved layout or styling changes.
- Explain the main clarity improvements in a short summary.
