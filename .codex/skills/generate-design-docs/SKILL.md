# Generate Design Docs

Write documentation that helps designers and engineers use UI patterns consistently.

## Workflow
- Identify the component or pattern scope before writing guidance.
- Document purpose, states, anatomy, and intended usage in practical language.
- Include implementation-relevant notes when they affect behavior or consistency.
- Keep the document concise and focused on decisions other teammates need to reuse.
- Separate required rules from optional suggestions.

## Output
- Provide a usage guide.
- Provide brief design notes and rationale where helpful.
