# Figma To Code

Implement the requested UI and keep the output focused on frontend structure and styling.

## Workflow
- Identify the target screen, states, and constraints from the design input.
- Reuse existing project components, tokens, and layout patterns before creating new ones.
- Match spacing, sizing, hierarchy, and alignment closely to the design.
- Build responsive behavior early so desktop and mobile layouts stay consistent.
- Prefer semantic HTML and accessible labeling for interactive elements.

## Output
- Provide production-ready frontend code.
- Include the CSS or styling changes required to render the UI.
- Summarize any assumptions where the design input is incomplete.
