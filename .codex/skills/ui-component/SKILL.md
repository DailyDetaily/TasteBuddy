# UI Component

Create one reusable component that fits the project conventions.

## Workflow
- Define the component's responsibility and avoid bundling unrelated behavior.
- Prefer composable props and predictable defaults over one-off branching.
- Keep markup clear, styles localized, and naming consistent with the codebase.
- Add lightweight accessibility support appropriate to the component type.
- Show one realistic usage example in the existing app style.

## Output
- Provide the component code.
- Provide a short usage example.
- Note any tradeoffs if flexibility and simplicity are in tension.
