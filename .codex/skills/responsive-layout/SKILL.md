# Responsive Layout

Adjust layout behavior without losing the intended visual design.

## Workflow
- Audit the current breakpoints, overflow risks, and fixed-size elements.
- Start from the smallest viewport and layer larger-screen adjustments progressively.
- Preserve hierarchy and key visual anchors while allowing stacks, wraps, or resizing.
- Prefer flexible units, intrinsic sizing, and container-aware patterns over hard-coded values.
- Check text wrapping, tap targets, and media scaling as part of the fix.

## Output
- Provide the updated layout code or CSS.
- Explain the breakpoint strategy and the main responsive changes.
